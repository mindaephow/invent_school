## 이 조립도의 구조·고유 사실
- 스크립트 `scripts/assembly-tools/battlerobot.py`.
- 창고 표: 1, 3~4, 6~8, 11~13, 15~17, 19~20, 22, 27~29 = 창고 1 / 2, 5, 9~10, 14, 18, 21, 23~26 = 창고 2 / 완성 = 0. 번호표는 11번 "8·10", 16번 "15 뒤집기"만 있다.
- 8번부터 본체를 z축 −45° 눕힌 자세(경사판 수평)로 이어간다. 옆판 두 벌은 점대칭(오른쪽 판은 열이 −X), 모터는 서로 반대 방향이라 십자 구멍 x 가 105.4(왼쪽)·85.4(오른쪽), 바퀴 축은 판 열7(왼쪽 x135.4, 오른쪽 x55.4).
- 8번은 뒤집은 그림이지만 뒤집지 않은 자세로 만들었다(작성 당시 보고에 적음).
