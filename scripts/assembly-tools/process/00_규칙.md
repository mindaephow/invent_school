# 규칙 마스터 — 조립도 작업 규칙의 원본 (2026-11-02 정리, 규칙 번호 A1~J7)

**이 파일이 조립도 규칙 문장의 원본이다.** `SKILL.md`·`05_조립.md`·`CLAUDE.md`·`문서지도.md`·안내서·`메모리_규칙/` 는 이 파일을 가리키고, 새 규칙은 여기에만 적는다(번호는 주제 글자+번호). 규칙 끝의 표시: `[도구]` = 도구가 막는다 · `[문장]` = 문장만 있다(도구로 올릴 후보) · `[충돌→확정]` = 문서끼리 달랐던 것을 정리한 결과 · `[새 규칙]` = 2026-11-02 해머배틀 15번 사고에서 추가. 출처 표기(`SKILL:20` 등)는 합치기 전 원본 위치로, 원본을 이 파일을 가리키게 줄이면서 사라진다.

## 00. 조립도를 시작할 때 (조립도당 한 번 — 번호 조립 전에 03·04 를 모두 끝낸다)

조립도를 시작하면 **03 부품 정리와 04 창고 정리를 모든 번호에 대해 먼저 다 하고, 그다음에 1번부터 조립한다**(A1~A3). 순서는 01 번호 등록 → 02 이미지 자르기 → **03 부품 정리 → 04 창고 정리 → 05 번호별 조립**이며 앞 과정이 끝나기 전에는 05 로 넘어가지 않는다.

- **03 부품 정리(모든 번호 한 번에):** 책 1번부터 끝 번호까지 순서대로 읽어 번호마다 새로 쓰는 부품·개수를 표(`USED`)에 적고(2개 만들기 번호는 2배), 부품별 합계를 교재 LIST 와 맞춘다. 안 맞으면 숫자를 고치지 말고 책을 다시 뒤져 어느 번호를 잘못 읽었는지 찾는다. **합계가 다 맞을 때까지 04 로 넘어가지 않는다.**
- **04 창고 정리(모든 번호 한 번에):** 같은 순서로 책을 읽으며 번호마다 창고(slot)와 `history`(창고가 바뀌는 번호), 숨길 앞 번호(`hideMade`)를 정한다. 연달아 이어지면 같은 창고, 새 세트가 시작되면 새 창고(원점), "N + M" 합치기는 작은 번호 창고로.
- 둘 다 끝나면 읽기 표 칸이 생긴 번호부터 아래 "0. 번호 하나 체크리스트"로 1번부터 조립한다. 조립 도중 부품·창고가 어긋난 것을 발견하면 조립을 멈추지 않고(B5) 03·04 표를 고친 뒤 이어간다.

## 0. 번호 하나 체크리스트 (1쪽 — 번호마다 이것을 먼저 읽는다. 상세는 괄호의 규칙 번호)

1. **시작:** 서버·로그인·`.env.local`(J5) → `number_start.py <이름> N`(A1) → 이 체크리스트를 읽고 "이번 번호에서 지킬 규칙 3개"를 첫 보고에 적는다(A6) → 앞 번호까지 만든 모델·읽기 표·창고·남은 부품에서 먼저 읽는다(`pegprobe`, A6).
2. **03 부품·04 창고가 끝났는지 확인:** 사용 부품 합계 = LIST(A2), 번호마다 slot·history(A3·A4). 안 맞는 것이 남아 있으면 번호 조립을 시작하지 않는다(A1).
3. **책 읽기:** 이번 번호 + 앞·뒤 번호 + 완성 사진(00)을 4~6배 확대해 부품·초록 링·**화살표가 시작하는 돌기**를 하나씩 센다(H1·G7). 책 그림 속 글자(뒤집기 화살표 등)를 읽는다(F8). 개수는 센 값만, 짐작은 "추정"(G13).
4. **격자·방향:** 기준 부품(결합을 받는 쪽)을 정하고 → 모서리 4곳 `crop_ticks` → `holefit`(통과 못 하면 C3 순서, 멈추지 않음) → `hf` 그림을 눈으로(D1). 결합하는 부품과 결합되는 부품 **양쪽**(D2). 판 폭·개수는 가까운 쪽 간격으로(D6). → `axes_fit`(오차 ≤2px, E1) → `rotate_to`(E3) → `refs_rect` → 축선과 실제 구멍의 거리(D7) → **그림은 만들자마자 DB 에 올리고 🖼 배지·그림 목록에서 확인한다(I1 — 올리지 않고 멈추거나 넘어가지 않는다).**
5. **읽기 표:** 면·링·부품·대조·방향·부품방향·부품 리마인드·판단과정(H7·E4·E5). 같은 조립이 둘이면 방향 가정 금지(F1), 합치는 번호는 뒤 번호부터(F3).
6. **놓기:** `attach`/`recv` 를 `p=` 없이(C6), 부품별 규칙(G1~G16), 방향이 불확실하면 가설을 모델로 만들어 비교(F4·E7). 새 창고는 원점(A4).
7. **빌드:** `build.py <이름> --write`, 끝줄 ❌(C5) → 결합마다 구멍-돌기 거리 0.0·바닥·겹침·화살표 수(G12).
8. **화면 확인:** 전체를 새로 불러와(J2) 책과 **같은 시점**으로 비교 → **6방향을 크게**, 모델이 보이는 화면에서(H2) → 관찰 기록(결합 2곳+6방향 1곳, H1) → 다음 번호(없으면 완성 사진)에서 이 조립이 적용된 모양을 센 값으로 비교(A8·H4).
9. **끝:** `record_check`(H3) → 이 번호의 그림이 DB 에 다 올라가 화면에 보이는지 확인(I1 — 규칙 순서를 지켰다는 증거) → `rulecheck`(A7) → 확인용으로 바꾼 카메라·팝업을 기본으로 되돌림(J1) → 보고(한 것/⚠/못 한 것, H8·J4) → 번호가 끝났으면 다음 번호로(사용자 답을 기다리지 않음, B5).
10. **푸시:** 사용자가 "업로드"라고 할 때만(I2).

문제가 생기면 멈추지 않는다: **먼저 이 체크리스트를 순서대로 지켰는지 확인** → 책을 뒤진다(B5~B6). 도구·검사가 막을 때: C1~C3. 사용자가 틀렸다고 할 때: B2.
