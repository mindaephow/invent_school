## 조심할 것(이번에 사용자가 화낸 것)
- 측정 도구가 낸 "이상한 결합"은 **교재 설명(단계 note)·화면으로 먼저 확인**하고 내놓는다(느슨한 `_mate` 오탐: 돌기 하나가 판 두 장·리벳이 판 세 장 등). 점검기는 `inside()` 엄격 판정과 이전 번호 중복 제거(`view`)를 쓴다.
- 부품 방향은 **돌기가 아니라 책 그림의 부품 모양·특징**으로 정하고, 기준은 월드 X·Y·Z 가 아니라 같은 로봇 안의 다른 부품(앞·뒤·위·아래)이다. 돌기가 대칭인 메인보드는 돌기만 맞추면 앞뒤가 거꾸로 놓인다(G8).
- `[확정]` 은 사용자가 직접 말한 것만. 추정은 `[가정]`·`[집계]`.
- 시킨 일은 묻지 않고 한다. 질문만 하고 턴을 끝내지 않는다. 사용자는 "수정하라"고 하면 ✓ 와 상관없이 고치길 원한다(관리자 지시 2026-11-03).
- `get_part_faces` 등 MCP 도구는 배포된 데이터 기준이라 `--write` 전 옛 값일 수 있다(soccer 23 에서 옛 방향을 현재로 착각).
