## 현재 상태 (2026-10-14, 도구로 확인)
- 조립도 35단계+완성 작성됨(`catapult_asm.json`). 사용자 ✓: 1~36번 전부(완성 포함). `python rulecheck.py catapult` = ❌ 0 / ⚠ 31번 / ✅ 1번.
- 정확한 현황은 `python number_start.py catapult <번호>`(✓ 번호)·`python rulecheck.py catapult`(규칙 점검)으로 본다.
- ✓ 한 번호의 내용은 바꾸지 않는다(빌드가 막는다). 고쳐야 하면 사용자가 ✓ 를 풀어 줄 때만 열린다.

## 구조·고유 사실
- 스크립트 `scripts/assembly-tools/catapult.py`. 번호 하나의 도구 순서는 `05_조립.md`.
- **19~22번(팔과 지렛대):** 20번 긴 팔은 `move_made`(제자리), T축·부시는 결합하는 모습(떠서 화살표). 21번은 14~20번 조립 전체를 `move_made` 로 몸의 세운 판 사이로 옮긴다(여러 번 이동 지원: `moves`, `IVS_moveAt`) — 팔은 29프레임 두 장 사이에 끼워지고 T축은 판·팔·판을 꿴다. 22번은 부품 없는 단계가 아니다 — 긴 팔(14~20번 조립)이 21번 T축을 중심으로 지렛대처럼 75° 선다(`move_made`, 10번 2단블록에 걸리기 직전 각도).
- **고무줄:** `bands`(노란 관: 바깥·구멍 통과·8자·팽팽, 규칙은 `05_조립.md` 5-6). 22번 이후 `bandsAt` 로 이어 그려진다(23·28·29번 `bandsHideAt`). 35번(부품 없음)은 모터 케이블을 흰 선 `bands` 로 그린다.
- **24~35번:** 24번 ㅍ 다리 X 방향(z ±10, 돌기 x 40·50·60), 단독 3단블록 Z 방향(x 130) — 책 축을 판 구멍으로 재서 정정한 것. 25번 흰 59프레임 x −40~40, 검은 39프레임 x 50~130. 26번 DC모터 앞면 = +y 면(돌기 2개 간격 40 + 빨간 십자 축), 옆돌기가 아래로 판 칸4·칸6. 27번 위 37프레임 칸2·칸4, 앞 37프레임 칸1·칸5(모터 기준 축). 28·29번 새 창고 2 큰기어 조립. 30번 기어 중심이 모터 출력축, 조립이 `R30` 로 서고 T축. 31·32번 중간바퀴(바깥 부시, 31번부터 전체 27mm 올림 `xform`). 33번 315프레임 칸6·칸10. 34번 메인보드 칸11·칸13(앞 끝에서 3·5번째). 35번 케이블 흰 선.
- **완성 화면 팔 당기기·장전·발사:** `def.hinges`, `design-assembly.js` `setupHinge`, `hinge_sweep.py`. 모터 각도 −25°/−40°·contact 68°·max 75° 는 사용자가 확인했다. 22번 데이터는 건드리지 않고 정의 쪽에만 둔다.
- **홀라인(2026-10-12 기록):** 34·35번은 흰 판 격자(평균 0.6px)로 축을 새로 만들었다. 26·27·30번은 `fits/NN_W.json` 만 만들어 뒀고 그림·축 json 은 예전 값이다(필요할 때 `refs_rect.py` 를 다시 돌려 반영). 31·32·33번은 모서리 눈대중이 안 맞아 통과하지 못했다(31번 평균 2.17px).
- **뷰어 기능(이 조립도 때 추가):** 선택 패널 이동량(mm) 입력칸(좌/우/높이/앞/뒤 버튼 이동 거리), 창고 그룹 줄을 누르면 먼저 그 그룹을 골라 파랗게 표시하고 한 번 더 눌러야 해제, `bands`(노란 관·흰 줄).

## 알아 둘 것
- 묶음 둘이 서로 거울 모양이면 한 개씩 다른 자리(왼쪽 L·오른쪽 L)에 같은 회전으로 들어간다 — 돌기 모양으로 먼저 수치로 확인한다.
- 새 부품이 있는 번호는 화면에서 화살표가 나오는지 직접 본다(`IVS_MATES.check`, 부품 DB 구멍 `len`). 리벳·T축·부시는 항상 결합하는 모습(띄워서 화살표)으로 둔다.
- `build.py --write` 가 읽기 표 빈 번호 때문에 조용히 막힐 수 있다 — 출력 끝의 ❌ 줄과 `기존 항목을 바꿨다` 를 확인한다.
- 줄이 둘인 프레임의 격자는 `center_row`, 사용자가 "회전"이라고 하면 `level` 로 실제 회전하고 각도를 보고한다. 이 조립도에서 사용자가 바로잡은 것은 `user_diffs/요청차이.md`(18·20번 항목)에 있다.
