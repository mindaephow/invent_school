## 이 조립도의 구조·고유 사실
- 스크립트 `scripts/assembly-tools/dog.py`. 2026-10-08 에 사용자 지시로 1~10번을 지우고 규칙대로 새로 시작했다.
- 좌표계: 판이 서 있다(홀면 +Z, 칸1 −X, 줄1 위 = 모델 줄3). 둘째 벽(6~9번)은 첫째 벽을 거울 칸(16−칸)에 두되 모터만 면 법선 180°로 놓은 것이다. 10번에서 둘째 벽을 세로축 180° + z 75 로 첫째 벽 맞은편에 옮겼다(모터 윗돌기 간격 40, 블록 끝돌기 간격 60).
- 11번 "뒤집기"는 `A.meta["xform"]`(가로축 180°, t y83 z75)로 전체를 뒤집고 새 부품은 뒤집기 전 좌표로 쓴다. 14번 "돌리기"도 같은 방식. 17번 이후 부품은 화면 좌표로 쓰면 파일 끝 루프(`_inv_xf_part`)가 역변환해 저장한다 — **새 코드는 그 루프 위에 화면 좌표로 쓴다**(dog.py 안에서 import 해 보면 이미 역변환된 값이 나온다).
- 블록 종류: 17·18번 3단블록, 19번은 큰 구멍 2·돌기 2 = 2단블록(19번은 37프레임 2 + 2단블록 4). USED 합계가 LIST(2단 9, 3단 10)와 안 맞으면 뒤 번호(21·31·37·41번 2단블록 7개 가정)를 다시 센다.
- 머리: 20번 = 19번 상자를 세워 흰 판 줄3 칸7·칸9 에 합침, 23·24번 = 눈 달린 39프레임을 −X·+X 쪽에 붙임(눈 = 판 칸6 위 줄), 25번 = 머리를 몸 37프레임 칸4 줄3·27프레임 칸4 줄2 에 얹음(머리 칸1 쪽이 몸 앞 −X 로 튀어나옴).

## 기법·함정
- **한 부품이 두 번 합쳐질 때(머리: 20번 + 25번)**: `move` 는 한 번뿐이다. 첫 합체는 `lift{from,at,by,dir,hover}`(내려와 결합, 평행이동만) + 세운 자세를 `poseAt[20..24]`, 둘째는 `move@25`. 합치는 단계만 있는 번호는 `noPart=True` 로 두어야 design-mates 검사가 통과한다(lift 는 검사가 모른다). `step.index` 는 교재 번호(1부터) — 머리 부품은 17~24.
- 합치는 단계(번호표만, 새 부품 없음)는 포뮬러원 21번처럼 옮겨 붙는 쪽 부품에 `extra["move"]={at,p,r,dir,hover}`·`moveGroup`·`moveGuide`·`move["marks"]`. **`dir` = 띄우는 쪽(최종 자리에서 멀어지는 방향)** — 반대로 쓰면 "띄우는 길에 다른 부품" 경고가 난다. 카메라는 focus 점 목록(`cam[3]`)으로 전체가 보이게 한다.
- 사용자가 저장한 📷(`ivs_assembly_cams`)가 있는 단계는 그 시점이 기준이다 — 같은 판을 다시 그릴 때는 SELECT 로 theta 를 읽어 맞춘다(18번 5.176, 20번 같은 방위).
- T축·돌기 pos 는 돌기 가운데(attach 가 돌기 시작면을 구멍 입구에 맞춤). T축 13번: 구멍 칸8 줄2 → 모터 cross_back, 바깥으로 21mm 당겨 돌기 끝이 소켓에 닿게.
- 격자: 판마다 level → lshow → lfit → render. `refs_cli.py level` 은 수평선 중점을 캔버스 가운데로 옮겨서 선 아래쪽이 잘린다(19번 아래판은 격자를 못 만들고 위판만). lshow/lfit 좌표는 돌린 그림 좌표(M 으로 변환해 계산). 판 격자 출력 칸 번호는 그림 자연 방향(왼→오)이라 거울 벽은 코드 칸 = 16−그림 칸. 격자는 만들 때마다 바로 DB 등록.
- 화면 확인: 설계를 "불러오기"로 열지 말고(저장된 설계를 지우는 버튼이 있어 위험) 차시(13)만 고르면 조립 보기가 열린다. 자동화 때는 새로고침 → 불러오기 첫 버튼 클릭(`#startOverlay`) → 13차시 select → 단계 버튼 두 번 클릭. `window.__ivsAssemblyBridge.turn()` 은 카메라만 바꾸니 쓰되 guides 를 hook 해서 화살표 구멍 id 를 읽어 검증한다.
- 교재 이미지 `refs/dog/07.jpg` 의 "02" 표시 원을 지워서 덮어썼다.
