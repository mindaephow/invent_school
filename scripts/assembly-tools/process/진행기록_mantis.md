# 사마귀로봇(cubo-2-mantis, 큐보 2권 4차시) 진행기록

쓰는 법: `문서지도.md` "진행 기록". 이 조립도는 메모리에 진행 메모가 없었고, 드롭체커 진행기록 안에 한 줄만 있던 내용을 2026-10-14 에 여기로 갈랐다.

## 현재 상태 (2026-10-16)
- **1~11번을 만들었다**(`python build.py mantis --write` 통과, 몸통 겹침 0, 단계별 검증 0 문제). 사용자 ✓ 는 없고 8·9·10·11번은 책↔화면 비교 증거(`record_check.py`)를 남겼다. 이미지(NN·NN_1 홀라인·NN_2 카메라)는 2~11번 DB 등록 완료.
- 1~4번 둘째 벌은 새로 만들지 않고 복사해 창고 2에 보관(`copy_to_slot`, 꺼내는 번호 19는 계획표 값 — 확인 필요).
- 9번 "반대로 돌리기" = 8번 조립품을 x축 +90°로 세워 판(515프레임)이 서 있는 자세(`move_made`, 줄 방향 ±Y 해만 roll 0°). 블록 둘은 판에 수직으로 서서 끝 돌기 하나로 끼운다.
- 10번 작은바퀴(축 끝에 다가옴), 11번 19프레임(구멍 1·5·9 = 블록 A 돌기·축·블록 B 돌기)·부시.
- 정확한 현황은 `python number_start.py mantis <번호>` 로 본다.

### 열린 사항 (사용자 확인 필요)
1. **9번 블록 종류**: 03 사용 부품은 '2단블록 1·3단블록 1'인데 11번 링 깊이 계산(두 블록 링이 판에서 같은 깊이 24mm = 2단블록 길이, 3단은 10mm 어긋남)과 그림(큰 구멍 2개)으로 **2단블록 둘**로 읽었다. 블록 구멍 방향(길이축 둘레 90°)도 추정.
2. **축 길이/깊이**: 8번에서 사용자 지시로 축을 책보다 깊게(끝 y −10.5) 넣었는데, 9·10·11번 책 그림으로 측정한 축 끝은 판 앞면 중심에서 약 33mm(모델 45.5mm)로 약 11mm 차이. 10·11번은 블록 기준으로 놓아 축이 19프레임 앞으로 길게 나온다.
3. 6번 조립품 위치(34mm 띄운 분해도 가정)·27프레임 줄·높이, 3·4·7·8번 구멍 점(눈으로 찍음), 3번 카메라(2.56px 추정), 작은바퀴 면(책은 바큇살 면이 카메라 쪽, 화면은 허브 십자 면)·바퀴 높이·부시 위치.
4. 11_P 격자는 바퀴·빨간 리벳이 가린 3곳(5.3·6.3·7.4)을 눈으로 확인해 제외하고 맞춤(평균 0.24px).

- 이어서 만들 때는 `CLAUDE.md` → `05_조립.md` 맨 위 "실행 순서"대로 하고, 완성 사진과 방향선 그림(`refs/mantis/00_1.jpg`)이 한 세트로 있어야 `number_start.py` 가 번호를 시작시킨다(`00_개선규칙.md` 9번).
