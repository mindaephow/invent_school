# 사마귀로봇(cubo-2-mantis, 큐보 2권 4차시) 진행기록

쓰는 법: `문서지도.md` "진행 기록". 이 조립도는 메모리에 진행 메모가 없었고, 드롭체커 진행기록 안에 한 줄만 있던 내용을 2026-10-14 에 여기로 갈랐다.

## 현재 상태 (2026-10-16)
- **1~16번을 만들었다(아래 17~30번 추가)**(`python build.py mantis --write` 통과, 몸통 겹침 0, 단계별 검증 0 문제). 사용자 ✓ 는 없고 8~16번은 책↔화면 비교 증거(`record_check.py`)를 남겼다. 이미지(NN·NN_1 홀라인·NN_2 카메라)는 2~16번 DB 등록 완료. 1~11번은 푸시됨(8688fc5), 12~16번은 로컬(푸시 전).
- 1~4번 둘째 벌은 새로 만들지 않고 복사해 창고 2에 보관(`copy_to_slot`, 꺼내는 번호 19는 계획표 값 — 확인 필요).
- 9번 "반대로 돌리기" = 8번 조립품을 x축 +90°로 세워 판(515프레임)이 서 있는 자세(`move_made`). 판 격자 칸 번호는 그림 칸1 = 팔이 붙은 끝(모델 +X 끝, 모델 칸 16−그림 칸).
- 12번 큰기어·T축 2개(새 창고 **3** — 창고 2 는 복사본 보관 중이라 계획표의 2 에서 바꿈, `hideMade` 로 1~11번을 창고 1 에 보관) → 13번 평행이동으로 판 뒤에 합침 + 부시 → 14번 블록 셋(2단 2·3단 1) → 15번 29프레임 → 16번 DC모터·3단블록.
- 깊이는 같은 번호 카메라로 링 픽셀을 역투영(같은 줄 X·Y 고정, Z 구함)해 정했다(11·13·15번). 13번 기어 위치는 15번 계산으로 7mm 고쳤다.
- **17~30번도 만들었다(2026-10-16)**: 17·18 첫째 유닛 마무리, 19~25 둘째 유닛(1~4번 복사 팔을 `R_FLIPX2` 로 뒤집어 판 줄이 거울: 그림 줄5 = 모델 줄1, 그림 칸 = 16 − 판 칸, 둘째 유닛 전체 z +5), 26 큰기어 세트(창고 3, 12번 세트를 면 둘레 180° 돌린 읽기), 27 합침, 28 블록 셋, 29 29프레임, 30 DC모터+3단블록. 21~30번은 모든 번호 `hideMade`(= `s19.kw["hideMade"]`) 로 첫째 유닛을 숨긴다. 23번은 첫째 유닛(x +90°)과 반대로 x −90° 로 세우고 x +5mm 어긋나게 세운다(검사 오탐 방지). 17~30번 이미지(NN·NN_1·NN_2) DB 등록 완료, 사용자 ✓ 없음(책↔화면 증거만). 31번~ 미착수. 푸시 안 함.
- **카메라 근거가 약한 번호**: 21(22번 격자를 SIFT 호모그래피로 옮김, 인라이어 21), 28(2.6px — 상한 2px 초과, 27번 해와 일치해서 사용), **29·30(격자 실패 — 28번 해를 그대로 옮김, 홀라인 그림 NN_1·NN_2 의 점도 28번 것이라 그림과 맞지 않음)**. 이 번호들은 사용자 📷 로 맞추거나 구멍이 보이는 근거를 더 모아 다시 계산해야 한다.
- **추정으로 남은 것**: 26번 기어 바깥 T축 구멍(어느 구멍인지 책에서 안 보임 — 기어 90° 대칭), 23번 블록 자세(y 180° 대응)·종류(03 표와 불일치), 24·25 바퀴·부시 띄움 거리(10·11번 값), 30번 모터 윗면 돌기·전선 방향(화면 비교로만 확인).
- 정확한 현황은 `python number_start.py mantis <번호>` 로 본다.

### 열린 사항 (사용자 확인 필요)
1. **블록 종류(03 사용 부품 표와 어긋남)**: 9번은 03 표 '2단1·3단1'인데 11번 링 깊이로 **2단블록 둘**, 16번은 03 표 '2단블록 1'인데 링 20mm 간격·LIST 합계로 **3단블록**으로 읽었다(2단 합계 6번 1+9번 2+14번 2, 3단 합계 14번 1+16번 1 이 LIST/2 와 맞는다). 블록 구멍 방향(길이축 둘레 돌림)은 추정.
2. **축 길이/깊이**: 8번에서 사용자 지시로 축을 책보다 깊게(끝 y −10.5) 넣었는데, 9·10·11번 책 그림으로 측정한 축 끝은 판 앞면 중심에서 약 33mm(모델 45.5mm)로 약 11mm 차이. 10·11번은 블록 기준으로 놓아 축이 19프레임 앞으로 길게 나온다.
3. 6번 조립품 위치(34mm 띄운 분해도 가정)·27프레임 줄·높이, 3·4·7·8번 구멍 점(눈으로 찍음), 3번 카메라(2.56px 추정), 작은바퀴 면(책은 바큇살 면이 카메라 쪽, 화면은 허브 십자 면)·바퀴 높이·부시 위치.
4. 판 격자 신뢰도: 11_P(바퀴가 가린 3곳 제외), 14_P(검출 40% 경계, 검출점만 14_F 로 카메라), **15_P(가려져 직접 검출 불가 — 14번 격자를 SIFT 호모그래피로 옮김, 유추 격자)**, 16_P(오른쪽 8칸만, 큰 어긋남 배정 제외).
5. 3단블록 가운데 돌기(14번 칸4 줄1, 15번·16번)는 책에 링이 없지만 모델은 같이 맞물리게 했다(추정). 15번 책 링 7개, 화면 화살표는 8개로 보임.
