# 사마귀로봇(cubo-2-mantis, 큐보 2권 4차시) 진행기록

쓰는 법: `문서지도.md` "진행 기록". 이 조립도는 메모리에 진행 메모가 없었고, 드롭체커 진행기록 안에 한 줄만 있던 내용을 2026-10-14 에 여기로 갈랐다.

## 현재 상태 (2026-10-14, 도구로 확인)
- **틀만 있다.** 단계 40개의 뼈대(`mantis_asm.json`, 마지막 수정 10-11)는 있지만 **부품이 들어간 단계는 0개**다. 사용자 ✓ 는 없다.
- 교재 단계 그림은 잘라 두었다(`refs/mantis/` 43개 파일). `mantis_list.json`(교재 LIST: 2단블록 10, 3단블록 4, 15프레임 1, 19프레임 4, …)도 있다.
- 규칙 점검(`python rulecheck.py mantis`)은 "옛 조립도 — ⚠ 로만 표시" 모드이고 판정할 번호가 없다(0/0/0).
- 정확한 현황은 `python number_start.py mantis <번호>` 로 본다.

## 알아 둘 것
- 완성 사진상 집게 팔 2개 + 기어·바퀴 구조라 걷는 다리 로봇이 아니다(작성 당시 판단 — 책 단계 그림은 아직 읽지 않았다). 그래서 `ref_n족로봇.md` 대상이 아니다.
- 이어서 만들 때는 `CLAUDE.md` → `05_조립.md` 맨 위 "실행 순서"대로 하고, 완성 사진과 방향선 그림(`refs/mantis/00_1.jpg`)이 한 세트로 있어야 `number_start.py` 가 번호를 시작시킨다(`00_개선규칙.md` 9번).
