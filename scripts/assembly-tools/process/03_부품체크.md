# 과정 3. 부품 체크

(02 이미지 자르기가 끝난 뒤. 번호별 책 그림은 `refs/<이름>/NN.jpg` 를 쓴다.)

## A. 부품이 등록돼 있는가
1. `check_chapter_parts(volume, chapter)` → 교재 LIST 부품마다 DB 등록 / 3D 모델 / 연결점(checked·auto·없음) / 면 이름 확정 여부.
2. 상태별 처리:
   - **DB에 없음 또는 3D 모델 없음:** 교재에서 그 부품을 찾아(그림·치수) 등록한다 — `get_part_standard` 규격 → `make_part_stl` → `apply_part_to_db`. 모델 없이 그림만 있는 부품(예: 리모컨, 3P 케이블, 고무밴드)은 조립도 제외 대상이다. 번호 설명에만 적고 모델 부품 수에 넣지 않는다.
   - **연결점 없음 / auto(확인 필요):** 3D 뷰어(`/design.html?subject=robot` → "큐보 부품 전체 리스트", 🟢 연결점 버튼)에서 구멍·돌기 개수와 위치를 세어 확인하고, 틀리면 `set_part_connectors`. 현재 값은 `get_part_connectors` 로 본다.
   - **면 이름 미확정:** 안내서 4-1 확정 메모가 있으면 따르고, 없으면 `measure_part` 와 모양으로 앞뒤를 정해 기록한다. 이름이 맞게 나오는지 `python test_faces.py`.
3. **조립 프로그램에도 있어야 한다:** LIST 부품(N프레임 제외)이 `conn.json` 에 없으면 `partlib.py` 의 `OTHER` 에 `get_part_connectors` 결과(`measure_part` 실측)를 옮기고 `python partlib.py` 로 `conn.json`·`dims.json` 을 다시 만든다. 없는 부품 확인:
   ```
   python -c "import json,re;l=json.load(open('<이름>_list.json',encoding='utf-8'));c=json.load(open('conn.json',encoding='utf-8'));print([n for n in l if n not in c and not re.fullmatch(r'\d\d+프레임',n)])"
   ```

## B. 번호별 사용 부품 확인 (LIST 와 크로스 체크)
1. 번호마다 **새로 쓰는 부품의 이름과 개수**를 번호별 책 그림(`refs/<이름>/NN.jpg`)에서 읽어 표로 적는다. 리벳은 그림 옆 "(n)" 표시 숫자 그대로, 다른 부품은 그림에서 센 값(근거가 약하면 "추정"). 합치는 번호나 새 부품이 없는 번호는 "없음".
2. 그림에 "1~6번까지 2개 만들기" 같은 번호표가 있으면 그 번호들의 부품은 **2배**로 센다(드롭체커 6번). 부품 이름별로 번호 합계를 내서 교재 LIST 와 대조한다. **LIST 가 기준이다.** 합이 안 맞으면 숫자를 맞추려고 고치지 말고 그림을 다시 보고 어느 번호를 잘못 읽었는지 찾는다.
3. 대조가 끝나면 각 번호 설명(note) 아래 줄에 `▣ 사용 부품: 이름 개수, …` 를 적는다. 투석기 방식: 스크립트의 `stepchecks.apply(...)` 뒤, `A.save_links()` 앞에
   ```
   USED = {1: "315프레임 1, DC모터 1", …, 13: "없음(합치는 단계)"}
   for _i, _u in USED.items():
       _pp = A.steps[_i - 1].note.split("\n▣ 사용 부품:")
       _tail = ("\n" + _pp[1].split("\n", 1)[1]) if len(_pp) > 1 and "\n" in _pp[1] else ""
       A.steps[_i - 1].note = _pp[0] + "\n▣ 사용 부품: " + _u + _tail
   ```
   (스크립트는 Edit 도구로 고친다.)
4. 모델이 없는 부품만 나오는 번호(투석기 22번 고무밴드)는 빈 단계로 두고 `USED` 에는 "고무밴드 2 (3D 모델 없음)" 처럼 적는다. 고무줄은 단계 데이터 `bands` 로 그리고 모양·이어 그리기 규칙은 05_조립.md 5-6 "고무줄 사용 규칙"을 따른다.
5. 부품 이름은 `<이름>_list.json` 의 이름과 똑같이(예: LIST 의 "큐보너트" → DB 이름 "너트").
6. 보고: 번호별 부품 표 / LIST 와 맞는 부품 / 안 맞는 부품과 의심 번호. 안 맞는 부품이 남은 채로는 번호별 작업을 시작하지 않는다.
