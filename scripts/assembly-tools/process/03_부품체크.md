# 과정 3. 부품 체크

(02 이미지 자르기가 끝난 뒤. 번호별 책 그림은 `refs/<이름>/NN.jpg` 를 쓴다. **03 은 1차다 — 책을 대략 훑어 모든 번호의 사용 부품을 적고 합계 = LIST 를 맞추면 끝이며, 상세·정정은 번호 조립 중에 한다: 큐보 부품결합규칙.md A2a.**)

## A. 부품이 등록돼 있는가
1. `check_chapter_parts(volume, chapter)` 를 부른다 — 보는 것과 `checked`·`auto` 의 뜻은 `큐보 부품결합규칙.md` K3 "확인하는 순서" 1번.
2. 상태별 처리:
   - **DB에 없음 또는 3D 모델 없음:** `06_3D부품_만들기_등록.md` 순서로 등록한다(`get_part_standard` → `make_part_stl` → `apply_part_to_db`). 모델 없이 그림만 있는 부품의 처리는 규칙 A2.
   - **연결점 없음 / auto(확인 필요):** 규칙 K3 "확인하는 순서" 2~4번(`get_part_connectors`·`measure_part`·3D 뷰어 🟢 연결점)으로 확인하고 틀리면 `set_part_connectors` — 고칠 때 순서는 K3 "고칠 때 순서".
   - **면 이름 미확정:** 규칙 K4. 이름이 맞게 나오는지 `python test_faces.py`.
3. **조립 프로그램에도 있어야 한다:** LIST 부품(N프레임 제외)이 `conn.json` 에 없으면 `partlib.py` 의 `OTHER` 에 `get_part_connectors` 결과(`measure_part` 실측)를 옮기고 `python partlib.py` 로 `conn.json`·`dims.json` 을 다시 만든다. 없는 부품 확인:
   ```
   python -c "import json,re;l=json.load(open('<이름>_list.json',encoding='utf-8'));c=json.load(open('conn.json',encoding='utf-8'));print([n for n in l if n not in c and not re.fullmatch(r'\d\d+프레임',n)])"
   ```

## B. 번호별 사용 부품 확인 (LIST 와 크로스 체크)
1. 번호마다 새로 쓰는 부품의 이름과 개수를 읽어 표로 적고 LIST 와 대조한다 → `큐보 부품결합규칙.md` A2(2배 세기·LIST 기준·리벳 "(n)"·합이 안 맞을 때).
2. 대조가 끝나면 각 번호 설명(note) 아래 줄에 `▣ 사용 부품: 이름 개수, …` 를 적는다. 투석기 방식: 스크립트의 `stepchecks.apply(...)` 뒤, `A.save_links()` 앞에
   ```
   USED = {1: "315프레임 1, DC모터 1", …, 13: "없음(합치는 단계)"}
   for _i, _u in USED.items():
       _pp = A.steps[_i - 1].note.split("\n▣ 사용 부품:")
       _tail = ("\n" + _pp[1].split("\n", 1)[1]) if len(_pp) > 1 and "\n" in _pp[1] else ""
       A.steps[_i - 1].note = _pp[0] + "\n▣ 사용 부품: " + _u + _tail
   ```
   (스크립트는 Edit 도구로 고친다.)
3. 모델이 없는 부품만 나오는 번호 → 규칙 A2.
4. 부품 이름은 `<이름>_list.json` 의 이름과 똑같이 → 규칙 A2.
5. 완료 표시(번호판 위 "부품정리" "1차 완료") → 규칙 A2a. `build.py --write` 가 적는다.
6. 보고 형식·안 맞는 부품이 남았을 때 → 규칙 A2.
