# 과정 0. 번호 등록

## 준비 (시작 전에 확인)
- 개발 서버(포트 3178)가 떠 있다: `curl http://localhost:3178/design.html` 이 200.
- **사용자가 로그인해 둔 화면**이 있다 — 번호 버튼 확인(4-4)에 필요하다. 로그인은 사용자가 하고, 비밀번호는 입력하지 않는다.
- 발명학교 MCP 연결(`check_chapter_parts`, `get_textbook_page`, `run_sql`), `.env.local` 의 서비스 키(`build.py` 가 사용자 ✓ 를 읽음).
- `pip install numpy pymupdf`. 파이썬은 `PYTHONIOENCODING=utf-8` 을 붙여 실행한다(Windows). 작업 폴더 `scripts/assembly-tools`.
- 이미 만든 조립도가 있는 차시면 ✅ 완료 단계를 확인한다(`check_workspace(assemblyId)` 또는 `select step,status from ivs_assembly_status where assembly_id='<id>'`). 완료 단계는 건드리지 않는다.

## 1. 차시 찾기
1. `check_chapter_parts(volume, chapter)` → 교재 PDF 주소. (안 되면 `run_sql`: `ivs_textbooks` 는 권마다 한 행, `data.files[0].url` = PDF, `data.chapters[]` = 차시 목록, 큐보 카테고리 id `6fa8abd9-7684-47a2-bd7f-2bc9a6e3fbe6`.)
2. 교재 쪽 번호 = PDF 쪽 번호. 새 차시는 앞 차시 쪽수 뒤에서부터 PDF 를 넘겨 찾는다(목차·차시 제목 쪽을 먼저 본다). 앞 차시 쪽수 — 1권: 토끼 13~16, 양팔저울 17~23, 풍차 27~31, 로봇팽이 35~43, 3륜바이크 46~51, 축구로봇 55~60, 오토건 64~69. 2권: 투석기 22~28.
3. 차시 제목 글자(띄어쓰기 포함)를 조립도 `chapter` 와 똑같이 쓴다.

## 2. 쪽 이미지
- PDF 받기: `curl -o 파일.pdf <주소>` (공개 주소). `get_textbook_page(volume, page)` 로 받아도 된다(1권 일부).
- PDF → pymupdf 가로 2524px → 임시 폴더에 `cubo<권>_p<쪽 3자리>.jpg` (예: `cubo2_p022.jpg`). 차시 전체 쪽(완성품 쪽~마지막 쪽)을 만든다 — 02 가 이 파일을 쓴다.
- 쪽 이미지를 Read 도구로 열어 본다.

## 3. 번호 표
처음부터 끝까지 훑어(왼쪽→오른쪽, 위→아래) 쪽마다 어떤 번호가 있는지 적는다.
- 교재 번호 그대로가 조립도 단계다.
- 맨 앞 완성품 사진 = 0, 마지막 "완성" 그림 = 99. 둘 다 단계로 만들지 않는다("완성" 화면은 자동으로 붙는다).
- 헷갈리면 앞·뒤 쪽과 완성품 사진을 같이 본다.

## 4. 등록
1. 스크립트가 없으면 `python new_assembly.py <영문이름> "<차시 제목>" <권>` (`IVS_MCP_URL` 이 없으면 `--list '{"2단블록":9}'` 로 LIST 를 준다).
2. `<이름>.py` 에 쪽 표와 번호를 적는다(투석기 예):
```
A = Asm("cubo-2-catapult", "투석기", "교재 22~28쪽 · 투석기 (1~35단계)", camera={"target": [60, 20, 0], "radius": 380, "theta": 0.9, "phi": 1.0}, listNote="만드는 중 — 단계가 끝나기 전까지 LIST 개수는 안 맞는 것이 정상", guideMode="mates")
# 쪽 표: 22쪽 완성품·LIST·1~2 / 23쪽 3~8 / … / 28쪽 33~35+완성
_PAGE = {**{n: 22 for n in (1, 2)}, **{n: 23 for n in range(3, 9)}, …}
SKEL = [A.step("[교재 %d] (작성 전) 교재 %d쪽 — 번호만 등록한 뼈대. 번호 작업 때 채운다." % (_n, _PAGE[_n]), noPart=True) for _n in range(1, 36)]
for _k in range(1, 36): A.steps[_k - 1].cam = (-0.79, 0.95, False, None, None, None); A.steps[_k - 1].camSrc = "guess"
```
   "(채우는 중)" 은 빌드가 막으니 "(작성 전)" 을 쓴다.
3. 스크립트 끝(`A.save_links()` 앞)에 `import stepchecks; stepchecks.apply(A, "<이름>")` (없으면 `--write` 거부).
4. `python build.py <이름> --write` → 로그인된 화면에서 번호 버튼이 전부 뜨는지 눌러 본다(새로 연 첫 방문은 다른 번호를 눌렀다 돌아와 본다).
5. 스크립트는 Edit 도구로 고친다(파이썬 한 줄에서 `\n` 을 넣으면 파일에 진짜 줄바꿈이 박혀 문법 오류). 고친 뒤 `python -c "import ast;ast.parse(open('<이름>.py',encoding='utf8').read())"` 로 확인.
6. 뼈대(작성 전) 상태로 푸시하지 않는다.
