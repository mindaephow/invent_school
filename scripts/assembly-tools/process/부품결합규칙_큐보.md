# 큐보 부품 결합규칙 (사용자 확정 규칙의 원본)

**큐보 부품에만 적용한다.** 에이스랩·로보타미주니어·프로보는 부품 규격과 결합 방식이 달라 따로 정리한다(아직 안 함).
점검 도구: `python cubo_joint_check.py <이름|all> [번호]` — 규칙 2·5~10·13~15를 잰다. 규칙 1·3·4·12와 [미정] 항목은 아직 점검이 없다.
규칙 문장은 이 파일이 원본이다. 규칙을 바꾸면 이 파일만 덮어쓰고(옛 문장은 지운다), 도구에 올릴 수 있는 것은 `cubo_joint_check.py` 로 올린다. `[확정]` 은 사용자가 직접 말한 것, `[집계]` 는 조립도 20개에서 센 값(확인 전), `[가정]` 은 내 추정이다.

## 사용자가 정한 결합 규칙

# 사용자가 정해 준 바른 결합 규칙 (이것이 기준 — 집계값과 다르면 이쪽이 우선)

1. 프레임과 프레임을 연결하는 방법은 리벳, 블록.
2. 프레임을 리벳으로 결합했을 경우 프레임 사이에 벌어짐은 없다(틈 0).
3. 프레임과 프레임은 물리적으로 겹칠 수 없다.
4. 블록의 돌기는 프레임과 결합할 때 프레임의 면을 벗어나지 않는다.
5. 블록의 돌기는 프레임 두 개를 결합할 수 없다.
6. 프레임에 결합하는 서보모터·DC모터의 돌기는 블록 돌기와 길이가 비슷하므로 블록 돌기와 같은 규칙을 따른다(프레임 면을 벗어나지 않음, 프레임 두 개를 결합할 수 없음).
7. 큐보 돌기(리벳·블록·서보·DC모터 모두)는 길이가 판 두께(5mm)쯤이라 프레임 두 장을 통과할 수 없다 — 돌기 하나는 프레임 한 장의 구멍에만 들어간다. 리벳은 양 끝 돌기가 각각 한 장씩 맡아 두 장을 묶는다.
8. 리벳으로 결합한 모든 부품 사이에는 틈이 없다 — 프레임↔프레임뿐 아니라 블록↔프레임, 15프레임↔135도 프레임 등 리벳이 잇는 모든 쌍(규칙 2를 넓힘). 예: 드롭체커 8번 15프레임↔135도 프레임이 벌어져 있음(틀림).
9. 나사(볼트)로 결합하면 부품 사이에 틈이 없고, 나사 머리·끝이 프레임 면 위로 튀어나오지 않는다(드롭체커 8번 지적).
(가정 — 사용자 확인 전) 메인보드 돌기도 규칙 6과 같다고 보고 점검기에 넣어 둠. 집계에서 블록·모터와 같은 모양(깊이 0.0 89%)이라서.
10. 방향 있는 부품(메인보드 등)은 책 그림에 보이는 부품 모양·특징(버튼 줄·단자·케이블)과 같은 방향으로 둔다. 돌기만 맞추면 안 된다. 방향의 기준은 월드 X·Y·Z 가 아니라 같은 로봇 안의 다른 부품과의 상대 관계(예: 메인보드 버튼 쪽은 뒷판 반대쪽)다 — 완성품 놓는 방향이 조립도마다 달라서. 점검: cubo_joint_check.py 규칙10 + <조립도>_orient.json.
11. 메인보드의 방향은 무조건 로봇의 앞·뒤 또는 위·아래를 기준으로 정한다(버튼 줄이 로봇 앞쪽·뒤쪽인지, 윗면이 로봇 위·아래인지 책에서 읽어 <조립도>_orient.json 에 face 로 적는다).
12. 메인보드는 검은색이고 윗면의 노란 버튼 4개가 무조건 L 자 또는 ㄴ 자 모양으로 놓인다(큰 버튼 하나도 노란 버튼이다 — 검은 받침은 보드 몸체 색일 뿐, 별도의 검정 버튼이 아님. 책 롤링봇 12번·24번 확대로 확인: 작은 것·큰 것·작은 것·작은 것 순서). 이 모양이 곧 방향을 정한다(11번 앞·뒤 또는 위·아래와 같은 규칙, 점검기 규칙10에 반영됨).
13. 프레임과 블록을 돌기로 바로 결합할 때도 틈이 없다(리벳으로 결합할 때와 같다, 규칙 8). 모터·메인보드·센서의 돌기 결합도 같게 본다. 점검: cubo_joint_check.py 규칙13.
14. 8볼트와 너트로 프레임 2개를 결합할 때도 틈이 없다(프레임 2장이 딱 붙고 볼트가 그 두 장을 지나 너트로 조인다, 판 두께 합 10mm).
15. 12볼트와 너트로 프레임 3개를 결합할 때도 틈이 없다(프레임 3장이 딱 붙고 볼트가 세 장을 지나 너트로 조인다, 판 두께 합 15mm).

## 부품별 어떻게 결합하나

# 부품별 "어떻게 결합하나" 정리. [확정] = 사용자가 정해 준 것, [집계] = 조립도 20개에서 센 것(사용자 확인 전, 틀릴 수 있음)

■ 리벳
 [확정] 양 끝 돌기(p1·p2)가 각각 구멍 한 장에만 들어간다 → 두 부품을 한 장씩 맡아 묶는다. 돌기 하나가 판 두 장을 못 뚫는다(돌기 길이 ≈ 판 두께 5mm).
 [확정] 리벳으로 묶은 두 부품 사이엔 틈이 없다(프레임↔프레임, 블록↔프레임, 15프레임↔135도 프레임 등 전부).
 [집계] 꽂히는 곳: 프레임(1498건), 3단블록(158), 2단블록(79), 2열브라켓(76), 큰기어(34), 1열브라켓(20).
 [집계] 구멍 한가운데에서 0.5mm(프레임·브라켓), 2.0mm(3단블록), 1.5mm(2단블록·큰기어) 지점에 앉는다.
■ 블록(2단·3단·눈블록)
 [확정] 블록 돌기는 프레임 한 장의 구멍에만 들어가고, 프레임 면 밖으로 나오지 않는다. 프레임 두 장을 한 돌기로 못 묶는다.
 [집계] 프레임에 꽂힘(3단 1212건, 2단 696건), 깊이 0.0(한가운데) 90% 이상. 블록끼리도 꽂힘(3단↔3단 22, 2단↔2단 17 등).
■ DC모터·서보모터
 [확정] 프레임에 결합하는 돌기는 블록 돌기와 같은 규칙(한 장, 면 밖으로 안 나옴).
 [집계] DC모터 → 프레임 170건, 깊이 0.0 85~100%.
■ 메인보드·IR센서·LED센서
 [집계] 프레임에 꽂힘(메인보드 38건·IR센서 18건·LED센서 15건), 깊이 0.0 약 89%. IR센서는 2열브라켓에도 4건.
 [집계 19곳 — 사용자 확인 전] 메인보드는 돌기 2개(20mm 간격)가 프레임 구멍 2개에 한가운데(깊이 0.0)로 꽂히고, 몸체 바닥이 프레임 면에 딱 붙는다(틈 0, 32건 전부). 프레임 한 장 안의 같은 줄·같은 열 구멍 2개가 16곳, 서로 다른 프레임 둘에 걸친 곳 2곳(soccer 23번은 교재가 "흰 판과 검은 판 구멍에 들어가요"라고 적은 것을 화면으로 확인 — 정상, formula1 32번은 미확인), 프레임 구멍이 안 잡힌 곳 3곳(battlebike 7·kidknight 35·rollingbot 12). IR·LED센서는 [미정].
■ 볼트(8볼트·12볼트)·너트
 [확정] 나사로 결합하면 틈이 없고, 머리·끝이 프레임 면 위로 튀어나오지 않는다.
 [집계] 8볼트: 프레임 137건, 너트 92건, 2열브라켓 10건 / 12볼트: 프레임 46, 너트 46, 3단블록 16 / 너트: 프레임 136, 3단블록 16 등.
 [집계] 머리는 맨 위 면에 딱 붙고(0.0), 너트도 면에 딱 붙는다(0.0).
■ 축·T축·부시
 [집계] 축: 부시 151건, 프레임 37, 큰기어 24, 중간바퀴 23, 작은기어 17, 작은바퀴 16 / T축: 프레임 83, 부시 52, 큰기어 44, 작은기어 31, 작은바퀴 18, DC모터 17.
 [미정] 끼우는 깊이·돌출 규칙은 사용자 확인 필요.
■ 기어·바퀴(큰기어·작은기어·중간바퀴·작은바퀴·데코바퀴)
 [집계] 축·T축이 지나고, 큰기어에는 리벳도 꽂힘(34건). 결합 규칙은 사용자 확인 필요.
■ 브라켓(1열·2열)
 [집계] 리벳·볼트·너트·블록이 꽂힘. 규칙은 사용자 확인 필요.
■ 프레임↔프레임 연결 방법
 [확정] 리벳과 블록.
