# 스피드바이크(cubo-2-speedbike, 큐보 2권 1차시, 교재 13~19쪽) 진행기록

## 현재 상태 (2026-10-14, 도구로 확인)

## 이 조립도의 구조·고유 사실
스크립트 `scripts/assembly-tools/speedbike.py`, 규칙 `speedbike_rules.json`(strict·orient_check·placecheck).
- **자세:** 1·2번 (0.3, 0.95) 평평. 3·4번 x축 +90° 세움(`poseAt`, R3 = [[1,0,0],[0,0,−1],[0,1,0]], 카메라 (0.3, 1.25)). 5~8번은 책 5번이 아래에서 본 모습이라 z축 180° 뒤집기 + x축 +90° 세움(`_RF`, `poseAt`, 모터 왼쪽·옆돌기 위·십자면 카메라 반대쪽, lift 5 = 100 / 6~8 = 1). 9~12번 `xform at 9`(x축 +90°, `_T9S`). 13번 이후는 `_pre()` 로 xform 을 거꾸로 돌린 좌표(`poseAt` 13~37, 713프레임·14번 판·블록).
- **창고:** 1~8번 슬롯 1, 9~13번 슬롯 2(둘째 조립품 z = −110), 14번 슬롯 3(판 2벌 z −300/−360), 15번 history 임시. 20~26번 슬롯은 파일 끝 `{14:3, 17:4, 20:5, 21:5, 24:6, 25:6}` 로 덮어쓴다(앞 12~37번 일괄 2 를 덮기 위해). 몸 `hideAt`: 20·21, 24·25.
- **12번:** 첫째 조립품을 z축 180°로 둘째 조립품 뒤에서 올린다(축 x 85,15 → 65,135, 19프레임 칸2·9 + 215 칸7·14), `move at 12` + `moveGuide`.
- **13번(2026-10-10 재작업):** 몸은 12번 자세 그대로(돌리지 않음, `RG13` = xform 과 같음, `_T13` = (0, −66.5, −113.5)). 판 `C713` = (−25, 16, −139.25) 긴 쪽 z·몸이 +x 로 뻗음, 링 칸2·12 줄5·7. 둘째 모터 p3·p4 정확, 첫째 모터 p5·p6 은 z 6.5mm 어긋남(리벳 규약 6.5 피치 누적, 보고함). 너트 DB 연결점은 h1 len 14 로 바꿨다(볼트 화살표용).
- **15~19번:** 15번 27프레임 조립품 2벌을 215프레임 칸9·15(먼 쪽 칸7·1)에 move + solver(`_fit_asm`), 16번 빨간 17프레임 2장, 17번 39프레임 + 3단블록 2개(창고 4, z −480), 18번 그 조립품을 713프레임 칸3·칸11 줄1 에 세움(24회전 전수 검색), 19번 둘째 713프레임(돌기 6개 중 4개 오차 0, 첫째 모터 2개는 6.5mm 어긋남). 기본 카메라 (−0.45, 0.85) + focus.
- **20~26번:** 20(315프레임 + 2단블록 2, 창고 5), 21(19프레임), 22(수치풀이로 3단블록 바깥돌기에 이동), 23(리벳 4 + 19프레임), 24(빨간 17프레임 2 + 리벳 8 + 블록 4, 창고 6), 25(조립 2벌을 y방향 100mm 간격으로 놓고 115프레임 2장, 막대는 서 있는 벽), 26(네모 틀을 713프레임에, 8/8 풀이). 26번 격자는 자동 검출 실패(3점, 모서리 연장)라 신뢰도가 낮다.
- 7번 축만 180° 돌려 맞물림 화살촉이 축 끝에 보이게 했다. 화살표 머리는 `design.html` HEAD 9 / 굵기 0.75. 모든 부품 `noFreeze` 1~39(화면의 ❄ 모습 기록이 코드를 덮던 문제 때문).
- 30번 리벳은 1열브라켓 팔 끝 h1(+x 한 칸). 28번 리벳은 결합 전. 27~28번 그림: 흰 L브라켓(2열브라켓?) + 8볼트 + 너트 + 리벳(부품 모델 확인 필요했던 곳).
- `asmlib.floor_check` 가 `poseAt`/`move` 에 단계 기준 xform 을 적용하도록 고쳤다.

## 알아 둘 것
- 화면 확인은 로그인된 탭에서 한다(새 탭은 로그인이 필요). 저장된 모습 기록(`poseStore`)은 코드 위치를 덮으므로, 빌드 후 낡으면 비운다(1~6번 비움).
- 25~37번에서 배운 일반 규칙은 `SKILL.md` "부품을 처음 놓을 때 규칙" 9~15번에 있다(막대 간격은 양 끝부터 구멍 세기, 해가 여럿이면 책 링으로 고정, 돌기 오차는 양쪽으로 나눔, 너트는 결합 반대쪽, 바퀴는 `measure_part` 로 면 확인, 패널을 숨겼으면 되살림). 여기에 다시 적지 않는다.
