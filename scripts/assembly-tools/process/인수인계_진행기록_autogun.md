# 오토건(cubo-1-autogun, 큐보 1권 7차시) 진행기록

쓰는 법: `문서지도.md` "진행 기록". 이 문서는 2026-10-14 에 Claude 메모리에서 옮겼다(메모리 원본 기록 시점 2026-10-02).

## 현재 상태 (2026-10-14, 도구로 확인)
- 조립도 33단계 작성됨(`autogun_asm.json`, 마지막 수정 10-03). 사용자 ✓ 는 한 번호도 없다.
- 단계 = 교재 번호 + 1(교재 7번을 7①·7②로 나눠서). 2026-10-02 에 사용자가 "여기까지 1차 완성"으로 본 상태다.
- 정확한 현황은 `python number_start.py autogun <번호>`·`python rulecheck.py autogun` 으로 본다.

## 이 조립도의 구조·고유 사실
- 스크립트 `scripts/assembly-tools/autogun.py`.
- 블록 종류는 초록 원 간격(이웃 2개 = 2단, 바깥 두 구멍 = 3단)과 LIST 합계로 확인한다. 14번은 위 3단·가운데 2단·B 끝 3단, 21번 T축 줄은 먼 쪽 x=55·95, 16번 맨 앞 블록은 돌기 하나가 판 밖이다.
- 30단계: 총몸+기둥이 떠서 내려오는 `lift`(뷰어 design-assembly.js). 32단계: 리벳 → 2열브라켓(긴 판이 프레임에 붙고 짧은 쪽이 발, joinOrder 2), 타깃 자리 TO=(130,0,220)·카메라 θ −1.1.
- 이 조립도용으로 뷰어에 추가한 기능: `cam.axes`(원점+조립 자리 기준선), `cam.focus/tight`, step `holeMarks`(프레임 구멍에 고정된 결합 원), `cam.holeNums`(제일 윗줄 구멍 번호 — 사용자 지시로 19단계만. 다른 단계에는 켜지 말 것). 번호 규칙: 블록 다음부터 1,2,3 · T축과 T축 사이 1,2,3.
- DC모터 새 모델(돌기 ±20)로 연결점·칠하기를 갱신했다. 풍차·로봇팽이·3륜바이크는 옛 모델 기준이라 어긋난다(미수정, 오토건만 수정 완료).

## 메모리 기록 시점(2026-10-02)에 남아 있던 미확인·추정 (이후 해결됐는지는 확인하지 않았다)
- 구멍 개수를 교재 확대 그림에서 직접 센 단계는 `autogun_rules.json` 의 count 에 있는 15·16·22번뿐이다. 17~21, 23~27, 26~29 등은 안 셌다(센 값은 양쪽 끝에서 일치하는지 본다).
- 카메라는 1·5·12단계만 계산값이고 20번 이후는 대부분 짐작이다. 30단계 기둥이 앉는 받침 구멍 위치도 교재 대조가 안 됐다.
- 14번 이후는 LIST 개수·구조 추측으로 만들었다가 연달아 틀린 적이 있어서(블록 종류·T축 줄·맨 앞 블록), 위 구멍 세기가 중요하다.
