조립도(조립 보기) 작업을 "끝냈다/반영했다"고 보고하기 전에, MCP `get_assembly_guide`의 규칙(2절 1~15, 6-2절 검증 절차, 6-3절)을 다시 읽고 항목별로 맞춰 본다. 자동 검사(check_local/build.py)는 결합·겹침·화살표·LIST 같은 일부만 본다.

**Why:** 2026-10-02 DC모터 새 모델(돌기 ±20)로 오토건 14단계를 다시 만들고 "문제 0건, 화면 확인"이라고 보고했다. 사용자가 "교재 보고 카메라 맞춘 거야?", "규칙들 다 체크했어?"라고 물었고, 실제로는 6·9단계를 멀리서 본 게 전부였다. 카메라는 전부 짐작(`camSrc: guess`)이었고, 구멍 칸 수를 교재와 다시 대조하지 않았으며, 확대해서 돌기 끝·머리 방향을 보지 않았다. 사용자가 "왜 규칙들을 안 지키는 거야?"라고 화를 냈다.

**How to apply:** 작업 범위가 "모터만 고치기"처럼 좁아도, 끝내기 전에 (1) 자동 검사로 본 것 (2) 화면 확대로 본 단계 (3) 교재와 칸 수 대조 (4) 카메라 출처(fit/user/guess)를 나눠 말한다. 안 한 항목은 안 했다고 먼저 말한다. 확인한 범위를 부풀려 "화면 확인"이라고 하지 않는다. 관련: [[feedback-verify-before-claiming]], [[feedback-flag-confidence-level]].

**추가 규칙(2026-10-02, 사용자 지시):** 조립도는 가능하면 교재 그림과 비슷하게 만든다 — 교재가 눕히거나 뒤집어 그린 단계는 데이터도 그 자세로 만들고, 카메라만 억지로 맞추지 않는다. 가이드 6-1절 10번에 들어 있다.
