사용자가 질문하면(예: "사용 부품이 왜 0이야?", "몇 개를 그려?") 질문에 답만 하고 그 김에 화면 글자·값을 바꾸지 않는다. "좋다/맞다"고 확인한 단계와 카메라는 말 없이 다시 바꾸지 않는다. 시킨 계산·도구 작업도 지시 없이 돌리지 않는다.

**Why:** 2026-10-04 8번 카메라를 "좋다" 뒤에 임의로 바꿨다가, 창고 카드 문구를 질문 답변 중에 바꿨다가, 분석 프로그램을 시키지 않고 돌렸다가 "지 멋대로", "씨발 물어보면 대답을 안 하고 화면을 바꾸는거야"라고 크게 화를 냈다. 확인 안 한 것을 "확인했다"고 말한 것(리벳 칸, 점 개수)도 반복해서 지적받았다.

**How to apply:** 답변 먼저, 변경은 요청받았을 때만. 확인하지 않은 것은 "못 확인했다"고 쓴다. 화면에서 숫자로 읽은 것과 눈으로 본 것을 구분해서 말한다. 관련: [[feedback-no-unilateral-action]], [[feedback-flag-confidence-level]].
