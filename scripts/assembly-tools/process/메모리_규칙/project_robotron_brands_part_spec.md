invent_school 로봇 카테고리 중 **에이스랩(1~4단계)·로보타미주니어(1~5단계)는 로버트론 회사 제품**이다. 2026-10-25 에 ivs_robot_categories + ivs_textbooks(차시 제목만, 부품·파일 비어 있음)로 등록함.

큐보 부품 규격과 다른 점(사용자 말, 2026-10-25):
- 프레임에서 **홀 테두리(구멍 둘레 링) 없음**
- **홀 크기 1mm 작음**
- 프레임 **두께 같음**, 전체 **사이즈 같음**
- **끝부분이 더 둥글게**

**Why:** 이 제품들의 부품·조립도를 만들 때 큐보 규격(`project_cubo_part_standard`)을 그대로 쓰면 안 맞는다.
**How to apply:** 에이스랩/로보타미주니어 부품(STL·shapes)을 만들 때 큐보 프레임 규격에서 위 네 가지만 바꿔 유추한다. 사용자가 요청하기 전엔 부품을 만들거나 기존 부품을 고치지 않는다. 관련: [[project-cubo-part-standard]]

**규격 확정·구현 (2026-10-25)**: 큐보 대비 — 구멍 입구 홈 없음·구멍 지름 4.5(반지름 2.25, 큐보 목 5.5보다 1mm 작음)·**구멍마다 가장자리 테두리와 같은 폭·높이 1mm 받침 고리**(사용자 지적: 고리가 없으면 가운데 판이 바닥에 안 닿음)·두께 5·팔 끝 모서리 반지름 3(안쪽 2). 생성기는 브랜드별 별도 파일: `app/lib/junior-frame-mesh.js`(로보타미주니어)·`acelab-frame-mesh.js`(에이스랩, 지금 값 같음), 공통 틀 `robotron-frame-mesh.js`. 리벳 `junior-rivet-mesh.js`(몸통 2.1·머리 2.6·가운데 마디 2.2). 등록 스크립트 `scripts/make-junior-parts.mjs [--write]`(큐보 프레임 18종+리벳을 새로 만들고 부시·축은 블랙 복사, 같은 이름은 행을 덮어씀). 색: 프레임 다홍색 #FF4B2B(design.html ROBOT_COLOR_HEX 에 추가), 리벳·부시·축 블랙. 에이스랩 부품은 아직 등록 안 함.

**부품을 DB 에 직접 넣은 뒤 반드시 3D 썸네일까지 (2026-10-25, 사용자가 "왜 3D 가 아니고 svg 야" 화냄)**: 설계 화면은 spec(3D 원본)을 내려받지 않고 `thumbnail3d` 가 있어야 3D 로 보여 준다. 없으면 복사해 온 옛 svg 가 뜬다. 스크립트로 부품 행을 쓰면 thumbnail3d 를 비우게 되므로, 그 뒤 index.html 부품 관리 → "✅ 골라서 그리기"에서 새 부품 id 만 체크해(JS 로 `#regenPickBox input` 의 value=id 체크) "고른 것 그리기" → 설계 화면에서 `img.part-icon-robot` 개수와 스크린샷으로 확인. 전체 다시 그리기는 큐보 썸네일까지 건드리니 쓰지 않는다. 등록 뒤 화면 확인은 끝에 하지 말고 등록 직후 한다.

**규격 수정 (2026-10-25 저녁)**: "구멍 받침 고리"는 오해였다 — 사용자 뜻은 **구멍 한 칸(10×10)마다 가장자리 테두리와 같은 네모 테두리로 둘러 구멍 사이에 선이 생기는 것**(15프레임이면 4줄), 구멍 둘레 동그란 고리는 없다. 팔 끝 모서리 반지름 4.5(안쪽 3.5, 짧은 변은 자동으로 줄임). 프레임 색은 사용자가 고른 **#F45243(R244 G82 B67, 이름 "다홍색")**, 부품 만들기 "자주 쓰는 색"에도 추가(parts-lab-partmaker.js·box-editor.js COLOR_PRESETS). 부품 수리실 부품 고르기 창에는 제품별(큐보/로보타미주니어…) 탭과 이름 옆 제품 표시를 넣음(parts-lab.html). 생성기는 칸 단위 타일로 면을 나눈다(전체를 한 번에 나누면 격자 안쪽 칸을 못 잇는다).

**출력용(프린트) 버전 (2026-10-25)**: "출력용 + 홀에 8컷팅" = 큐보 출력용과 같은 방식 — 목 지름을 프린터 오차만큼 넓히고(4.5 → 5.10, 큐보 5.5 → 6.10 의 +0.60 을 그대로 적용한 내 가정) 구멍 목에 홈 8곳(폭 0.8·깊이 0.3). 눕혀서 출력(두께 z, 바닥 z=0). `scripts/make-robotron-print.mjs <junior|acelab> [--write]` → 다운로드/로보타미주니어_출력용_홈8, 에이스랩_출력용_홈8, 주니어는 --write 로 부품 행 data.print 에 gzip+base64. 규격은 junior-frame-mesh.js·acelab-frame-mesh.js 의 *_PRINT_STD. 에이스랩은 DB 에 부품이 없어 파일만. 큐보용 register-print-stl.mjs/get-print-stl.mjs 는 이름으로 행을 찾아서 큐보·주니어 이름이 겹치면 못 쓴다.
