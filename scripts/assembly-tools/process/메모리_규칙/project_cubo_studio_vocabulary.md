사용자(2026-10-03)가 invent_school 조립도 작업 공간 전체를 "큐보 스튜디오"라고 부르기로 했다. 화면의 한 메뉴가 아니라 작업 방식의 이름이다. 말버릇 예: "큐보 스튜디오에서 오토건 조립도 수정 시작하자", "잘 되었는지 검토 시작하자", "조종형 비행기 조립도 만들자".

**Why:** 매번 긴 지시 없이 이 한 마디로 절차(안내서 읽기 → 만들기/수정/검토)에 들어가게 하려는 것. 새 PC·기억 없는 클로드도 같게 하려고 절차는 MCP 안내서 맨 앞 "큐보 스튜디오" 절(A 만들기 / B 수정 / C 검토)에 적었다.

**How to apply:** 이 말이 나오면 get_assembly_guide 를 읽고 해당 절차로 시작한다. 지시는 설득하지 않고 그대로 따른다 [[feedback-follow-admin-fix-instructions]]. 상태: [[project-autogun-status-1002]].
