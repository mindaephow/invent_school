강아지로봇 27~31번에서 카메라를 guess 값으로 두어 28·29번이 책과 거울로 보이고 25번은 머리가 반대로 튀어나왔다. 사용자: "수평 잡고 격자 보고 왜 카메라 방향을 못 잡아? 정확히 계산은 안 해도 어디가 어느 쪽인지는 맞춰야지", "작업 점검에 방향 파악이 없네?"(2026-10-09).

**Why:** 정밀 PnP 는 필요 없지만 좌우·앞뒤가 책과 다르면 학생이 거울로 따라 만든다.

**How to apply:** 번호마다 격자를 본 뒤 dog_read.json 의 '방향' 칸에 "가까운 쪽·오른쪽·위 = 로봇의 ±X/±Z/±Y"를 적고 theta 를 정한다(25번부터 stepchecks 가 비면 막음). 규약: theta 0 = +Z 에서 봄(오른쪽 +X), π/2 = +X 에서 봄(오른쪽 −Z), π = −Z 에서 봄(오른쪽 −X), −π/2 = −X 에서 봄(오른쪽 +Z); 책에서 "바깥(−Z)이 왼쪽 아래로 향하면" π 보다 크게(3.6), "판이 위 오른쪽으로 멀어지면" π/2 보다 크게(2.0). 만든 뒤 뷰어와 책 그림을 나란히 본다. 관련: [[project-dog-robot-restart]]
