배틀로봇을 시작할 때 안내서 "작업 흐름"을 안 읽고 쪽(91·92)부터 읽고 뼈대만 만든 뒤 "1~8단계"라고 말해 관리자가 크게 화냄("자동화·MCP를 만들어도 총감독이 병신") — 번호 등록·창고 정리 두 단계를 건너뛴 것.

**Why:** 이 순서 규칙을 관리자가 직접 만들어 둠. 지키지 않으면 앞 단계 보고·확인 없이 뒤로 가서 다 뒤엎게 된다.
**How to apply:** 새 조립도 요청이 오면 첫 행동 = `process/00_규칙.md` 읽기(맨 위 "00. 조립도를 시작할 때") — 번호 등록 → 이미지 자르기 → 부품 정리 → 창고 정리를 모든 번호에 대해 먼저 끝내고 그다음 번호 조립. 단계마다 결과를 짧게 보고하되 사용자 답을 기다리며 멈추지 않는다. 사용자가 "N쪽까지"라고 해도 앞 단계를 먼저 한다. 관련: [[feedback-do-only-the-stated-step]]
