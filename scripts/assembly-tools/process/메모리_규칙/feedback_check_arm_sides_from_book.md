바이킹 15·16번(2026-10-21): (1) 위에서 구멍이 다 안 보이면 바닥에 두고 위에서 본 그림이 아니다 — 누워 있다고 가정해 만들면 안 된다. 리벳·화살표 축이 세로에서 기울어 있으면 카메라 롤/세운 자세를 의심한다. (2) 결합 방향이 위아래가 아니라 옆일 수 있다 — 다음 번호 책(16번)에서 같은 부품이 어떤 자세로 붙는지 먼저 본다. (3) 같은 부품 둘(팔)은 '상자 가운데 180° 회전'으로 대칭이라 가정하지 말고 각 팔의 책 구멍 줄(직선 3D 풀이)·overlay 로 어느 쪽에 어떤 자세인지 맞춘다 — 먼 팔을 회전으로 놓아 블록 상자가 책과 어긋난 것을 사용자가 지적했다.

**Why:** 홀라인 작업을 제대로 했으면 알 수 있었던 것을 놓쳐 사용자가 여러 번 지적했다.
**How to apply:** 번호를 끝내기 전에 양쪽 팔·좌우 유닛마다 책 시점에서 모델 상자를 겹친 overlay 와 롤 보정한 책↔모델 나란히 그림으로 방향을 하나씩 대조한다.
