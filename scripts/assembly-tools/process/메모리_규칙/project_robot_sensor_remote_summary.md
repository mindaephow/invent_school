부품 관리 화면(public/index.html `sensorSummaryHtml`)이 로봇(브랜드) 탭마다 부품 이름에서 센서·리모컨을 뽑아 요약 칸 두 개를 보여 준다(2026-10-27 사용자 요청, 아직 커밋 전이었음).

- 센서 목록: 이름에 "센서"가 들어간 부품을 권별로 나열(수량 ×N). 리모컨수신센서도 여기에 적는다.
- 리모컨 칸: 이름에 "리모컨"이 들어간 부품(수신센서 제외)이 처음 나오는 권 → "N권부터 리모컨을 사용", 리모컨이 없으면 "없음".
- 리모컨이 처음 나오는 권에 이름에 "수신"이 든 부품이 따로 없으면 그 권 센서 목록에 "리모컨수신센서(메인보드에 포함, 센서 리스트에 없음)"를 자동으로 붙인다(큐보 1권 사례).

**Why:** 사용자가 로봇마다 몇 권에 어떤 센서를 쓰는지, 리모컨은 몇 권부터인지를 한눈에 보길 원한다. "앞으로 부품 등록하면 같은 방식으로 정리해줘"라고 지시했다.

**How to apply:** 새 센서·리모컨 부품을 등록할 때 이름 규칙(센서 = "…센서", 리모컨 = "…리모컨", 수신기 = "리모컨수신센서")과 권(volumes) 등록을 빠뜨리지 않는다. 등록한 뒤 해당 로봇 탭에서 요약 칸에 제대로 나오는지 새로 불러와 확인한다. 메타·프로보 커넥트·스카이 로보·X로보는 센서 부품이 아직 등록돼 있지 않다(2026-10-27 기준). 큐보 센서는 IR 2·LED 2·터치 1(수신센서는 메인보드 내장이라 개수에 넣지 않음). 관련: [[feedback-reload-and-show-after-part-register]]
