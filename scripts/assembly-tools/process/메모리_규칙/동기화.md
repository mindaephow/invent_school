# 메모리 ↔ 저장소 동기화 (2026-10-19)
외부 PC 도 같은 규칙으로 일하게 하는 장치다. 방향은 둘이다.

| 상황 | 하는 일 |
|---|---|
| **사용자 PC**: 조립도·invent_school 관련 메모리(`feedback_*`·`project_*`)를 새로 쓰거나 고쳤다 | 같은 턴 끝에 `cd scripts/assembly-tools && PYTHONIOENCODING=utf-8 python sync_memory_rules.py` → 복사 + `INDEX.md` 재생성. 푸시는 사용자가 "업로드"라 할 때(그때 외부 PC 가 pull) |
| **외부 PC**: 사용자가 새로 바로잡았다 | 외부 PC Claude 는 메모리에 쓰지 말고 이 폴더의 같은 이름 파일(없으면 `feedback_<주제>.md` 새로 + `INDEX.md` 에 한 줄)에 적는다. 사용자가 푸시 → 사용자 PC 에서 pull 한 뒤 `python sync_memory_rules.py --from-repo` 로 메모리에 가져온다 |
| 차이만 보고 싶다 | `python sync_memory_rules.py --check` |

- 필독 목록(맨 위)은 `INDEX_head.md` 를 고친다(`INDEX.md` 는 자동 생성이라 손으로 고치면 덮인다).
- 홍허브·영상 등 조립도와 무관한 메모리는 스크립트 `EXCLUDE` 로 빠진다.
- 외부 PC 는 **매 세션 시작에 `git pull` 부터** 한다(CLAUDE.md "이 PC 에 메모리가 없을 때" 1번) — 그래야 사용자 PC 의 새 교정이 온다.
