조향자동차 36번 25프레임에서 한 번호에 네 가지를 한꺼번에 어겨 사용자가 여러 시간 화냈다.

1. **어디에 결합하는지 모를 때 모델의 빈 구멍만 보고 끼웠다**(앞면에 세워 리벳 2개 → 책 44·45번엔 그런 모양이 없음). 눕힌 판이 위판 앞으로 내밀어 있었다. 그리고 사용자에게 "어느 구멍이냐"고 물었다.
2. **`recv` 에 `p=` 손 좌표를 넣어 자동 계산을 건너뛰었다**(2.5mm 뜸). `p` 없이 부르면 돌기 밑동에 아래면이 딱 닿는다.
3. **책에 없는 "리벳 2"** 를 설명문 숫자만 믿고 책에서 찾으며 후보를 만들어 보여 줬다.
4. **"책과 비슷하다"로 보고했다** — 숫자 확인(구멍-돌기 거리)이 없었다.

**Why:** 사용자는 "가장 기본이자나 — 어떤 부품을 어디에 결합할지 관찰하는 거"라고 했다. 규칙(05_조립.md 196행 "좌표를 손으로 계산해 place 로만 놓지 않는다")도 있었다. 규칙은 필요할 때만 벗어나는 것이다.

**How to apply:**
- 부품이 놓일 자리를 이 번호 책에서 못 읽으면: 뒤 번호 책(37·44·45…)과 완성 사진(00)에서 그 부품이 어디 있는지 먼저 찾고, 모델의 위·옆·앞 샷으로 비어 있는 곳을 보고, 구멍-돌기 개수·간격(예: 링 쌍 40mm×10mm)을 좌표로 대조한다. 사용자에게 묻기 전에 이것부터 끝낸다.
- 위치는 `recv`/`attach` 를 `p=` 없이 부른다. `p=` 를 넣는 것은 자동 계산이 안 되는 경우(축에 돌기가 하나뿐인 축 위 부시·바퀴 등, 다른 조립도도 그렇게 함)뿐이고, 그때는 코드 주석에 이유와 치수 출처를 한 줄 적는다.
- 사용 부품 숫자(설명문의 "리벳 2" 등)는 책에서 읽은 것만 쓴다. 책에 그림·글이 없으면 찾지 말고 지운다.
- 번호를 끝내기 전 결합마다 구멍-돌기 거리(x,y,z)가 0 인지 숫자로 보고한다(`part.hole(id)["pos"] - host.peg(id)["pos"]`). "비슷하다"는 쓰지 않는다.
