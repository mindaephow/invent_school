# 참고 — n족 보행 로봇 조립 (강아지로봇 4족 · 꼬마기사 2족) (2026-10-13, 사용자 지시 "n족 로봇을 조립할 때 참고할 것을 올려 두고 참고한다")

n족 보행 조립도는 **강아지로봇(4족)** 과 **꼬마기사(2족)** 다(사마귀로봇은 완성 사진상 집게 팔 2개 + 기어·바퀴 구조라 걷는 다리 로봇이 아니다 — 책 단계 그림은 아직 읽지 않았다). 둘 다 **몸통을 먼저 만들고 다리·팔을 따로(창고 2) 만들어 몸에 합치는** 순서이며, 다리가 좌우 대칭이다. 대칭 쪽 처리는 `ref_대칭조립.md` 를 같이 본다.

## 조립할 때 참고할 것
1. **몸을 창고 1 에 두고, 다리·팔·머리는 창고 2 에서 새로 만든 뒤 합친다.** 합치는 번호는 작은 번호 창고에서 합친다(04 창고 정리). "2개 만들기"는 같은 조립 두 벌 — 둘째는 뒤 번호에서 이어 조립한다.
2. **다리 두 벌은 서로 거울(또는 같은 조립을 반대 끝에 붙임).** 첫째를 끝까지 확인한 뒤 둘째는 거울 위치·자세로 만든다(`ref_대칭조립.md`). 꼬마기사 15번처럼 판 가운데 둘레 x 축 180° 로 붙이는 경우와, 강아지 36번처럼 "거울"로 만드는 경우가 있다.
3. **한쪽 다리·팔을 고치면 반대쪽에도 같게**: 꼬마기사에서 21~24번을 고치고 26번 이후 반대쪽에 적용하지 않아 지적받았다.
4. **서 있는 다리는 앞(+Z)에서 본다(눈대중 시점은 guess 라서 번호마다 격자에서 카메라를 계산한다).** 다리를 눕혀 만드는 번호(꼬마기사 13번)는 눕히는 변환(x 축 90°)을 코드에 적는다.
5. **보행 기어 구조(큰기어 + 작은기어 + T축)**: 큰기어 중앙 구멍·위쪽 구멍의 T축 방향이 앞·뒤로 반대(강아지 2번·꼬마기사 9번)다. `measure_part` 로 면을 읽고 놓는다.
6. **움직이는 팔·다리**: 꼬마기사 22~24번처럼 다리를 기울인 자세(poseAt)와 완성 화면 hinge 는 단계 데이터를 ✓ 잠금과 분리해서 정의 쪽에만 둔다.
