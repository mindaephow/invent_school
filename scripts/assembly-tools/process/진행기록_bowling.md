# 진행기록 — bowling(큐보 2권 11차시 볼링머신, cubo-2-bowling, 교재 100~107쪽, 1~37단계)

## 현재 상태 (2026-10-25)
- 사용자 지시: 처음부터 다시, 규칙대로(홀라인·X·Y·Z 축선·읽기 표·증거). **결합 위치(코드)는 사용자가 "잘 돼 있다"고 한 4번까지 그대로 둔다**(4번 끝 3단블록은 사용자 지시로 180° 돌림 — psi 139.5+180).
- 1~6번: 홀라인·축선·겹침 증명·번호 대조·읽기 표·증거·DB 그림 다시 만듦. 1·5·6번 격자는 앵커 유추(⚠ 사용자 확인 필요), 6번 `양쪽 홀라인` ⚠(18번부터 막힘).
- 6번: 5번 세트 둘을 벽으로 세워 3번 바닥(칸10·12 줄3·12)에 꽂음(`R_WALL6`, `move_made`).
- 7~37번: 아직 안 만듦(뼈대, USED 부품 표만 적음).

## 작업 중 알게 된 것
- 03 부품 대조(2026-10-25): 센 합계가 LIST 와 같음 — 리벳 66·8볼트 12·너트 12·2단블록 14·3단블록 14·315프레임 6 등. 안 맞음: 37프레임 LIST 6 ↔ 센 4(17·32번 ×2벌). 중간바퀴 2 = 107쪽 볼링공(단계 아님), 리모컨 = 모델 없음.
- 책 4번 끝 3단블록(3번·6번)은 책에서 서 있는 것으로 보이고(높이 ≈ 40mm), 5번에서 판 칸9 줄3 이 이 블록 윗 끝 돌기에 닿는다 — 모델은 사용자 지시로 누운 채 p5(4번)·p8(5번)·180° 돌림 상태이며 사용자가 이 결합이 맞다고 함. 건드리지 않는다.
