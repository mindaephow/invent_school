# 참고 — 대칭(거울) 조립 (2026-10-13, 사용자 지시 "대부분 대칭형이다 — 참고할 것을 올려 두고 참고한다")

**모범 사례 = 드롭체커.** 부품 93개 전부(100%)가 한 평면(713프레임 판 가운데 줄, z = 5)에 대한 거울 쌍이고 위치 오차는 0.00mm 다(`python symcheck.py dropchecker --축 z --중심 5`). 대칭 쪽을 새로 만들 때는 먼저 이것을 본다.

비율이 낮은 것은 대칭이 없다는 뜻이 아니라 몸통·머리처럼 비대칭 부분이 섞여 있다는 뜻이다. **대칭이 있는 부분(좌우 유닛·팔·다리·벽)은 한쪽 정보로 반대쪽을 유추한다.**

## 2. 거울 변환 공식 (드롭체커·꼬마기사 공통)
- 위치: 대칭면이 z = c 이면 `p' = (x, y, 2c − z)`. (x 거울이면 x 를 뒤집는다.)
- 자세: 같은 부품을 **돌려서** 놓는다 — `R' = M·R·M` (`M = diag(1,1,−1)` z 거울, `diag(−1,1,1)` x 거울). 부품 자체를 거울로 뒤집는 것이 아니라 같은 부품을 거울 위치·거울 자세로 놓는 것이다.
- 부품이 스스로 거울 대칭이 아니면(135도 프레임, DC모터, 메인보드 …) 거울 자세만으로는 되지 않는다 — 길이 축으로 180° 더 뒤집는다(드롭체커 `R_F135X = diag(1,−1,−1)`: 17번 둘째 팔은 7번 첫째 팔과 거울쌍이라 프레임을 뒤집어 짧은 팔이 반대쪽으로 꺾인다). 모터 면·돌기 면은 `measure_part` 로 읽는다.

## 3. 드롭체커에서 대칭을 만든 순서 (참고할 번호)
1. **1~6번 "2개 만들기"**: 같은 모터 유닛 두 벌을 앞뒤(z +50 / −50)로 나란히 — 둘째는 첫째와 같은 순서·같은 결합.
2. **7~10번 첫째 팔 → 17~20번 둘째 팔**: 7번과 같은 구성의 거울쌍(135도 프레임을 길이 축으로 뒤집음). 사용자 지시 "똑같은 거 만든 거 있잖아 반대편 거, 그거 보면 되잖아".
3. **21번**: 둘째 유닛 위치를 x 거울(`M = diag(−1,1,1)`, `R → M·R·M`)로 옮기고, 팔도 첫째 팔 최종 자세를 거울로 만든다.
4. **24번 "16 + 23"**: 둘째 유닛이 713판에 끼워지는 자리 = **16번 첫째 유닛의 줄 거울** — 칸 그대로, 줄 `r → 8 − r` (모터 칸6·8 줄2 → 줄6, 끝 3단블록 칸13 줄1 → 줄7, 리벳 칸1 줄1 → 줄7). 결과는 `symcheck` 로 0.00mm 확인.
   - **위치를 점수·후보 탐색으로 정하지 않는다.** 구멍 개수로 점수를 줬더니 볼트·너트 축에 구멍이 4개 쌓인 자리가 이기고 리벳이 너트 구멍에 끼워졌다(돌기 수 우선, 리벳은 가로 거리 + 구멍 길이, 볼트·너트 축 제외로 고침). 대칭 쪽은 반대편이 끼워진 그대로 따른다.

## 4. 다른 조립도의 대칭 처리
- **꼬마기사**: 다리 두 벌(9~12번 "2개 만들기"), 두 다리를 눕혀(13번) 한쪽 끝(14번)·반대쪽 끝(15번)에 단다(반대쪽은 판 가운데 둘레 x 축 180°). 팔은 21번 오른팔 → 27~29번 왼팔을 `_mirpose`(z = 0 평면 거울)로 옮긴다. **21~24번에서 고친 것을 반대쪽 26번부터 적용하지 않아 사용자에게 지적받았다("반대편 말이야")** — 한쪽을 고치면 반대쪽도 같게.
- **강아지로봇**: 6~9번 거울 벽(첫째 벽 1~5번과 같은 순서로 따로 만들고 칸은 `그림 칸 = 16 − 첫째 벽 칸`), 27번 다리 2벌(34·36번에서 둘째 다리 조립), 11번·40번 "N 반대로 뒤집기".

## 5. 규칙
1. **한쪽을 먼저 완성하고 반대쪽은 거울 위치에 같은 결합으로 만든다.** 반대쪽을 처음부터 다시 탐색하지 않는다.
2. **한쪽을 고치면 반대쪽에도 같은 수정을 적용하고 점검한다**(같은 종류 전부 훑기 — SKILL 규칙 8).
3. **검증은 `symcheck.py`**: 대칭 쪽 부품의 거울 위치 거리가 0.00mm 인지 본다(`--빠진것` 으로 짝 없는 부품 = 반대쪽에 아직 없는 부품을 나열 — 그 부품의 거울 위치가 반대편에서 놓일 자리다).
4. **한 번호 그림만으로 안 풀리면** 대칭 쪽 번호의 끼움 칸을 앵커로 쓴다: `infer_grid.py … --판 <앞번호>:<라벨> --거울 <대칭번호> 줄 --링 "x,y;…"` (05_조립 0-1 절). 링↔칸 짝은 도구가 모든 짝을 돌려 고른다(드롭체커 24번에서 손으로 정한 배정과 같게 나왔다).
5. 거울쌍으로 놓은 부품의 `R_*` 는 부품 DB 면(`measure_part`)으로 확인한다 — 모터·메인보드·기어 방향이 틀리면 뒤 번호가 다 어긋난다.
