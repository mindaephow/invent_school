# 과정 2. 이미지 자르기 (번호별 책 그림)

(01 에서 만든 쪽 이미지 `cubo<권>_p<쪽 3자리>.jpg` 를 쓴다. 로그인된 화면이 필요하다 — 사용자가 로그인한다.)

1. `refs_make.py` 의 `BOOKS` 에 차시 추가: `"<이름>": {"volume": 권, "pages": {쪽: [(번호, 상자, 설명), …], …}, "extra": []}`. 쪽마다 그림 6칸은 `[(3 + i, box(*g), "") for i, g in enumerate(GRID)]`, 첫 쪽은 `(0, 완성품 상자, "…완성품 사진 — 앞뒤·방향은 여기서 확인")`, 마지막 쪽 끝에 `(99, box(...), "완성")`. 첫 쪽 상자는 눈으로 보고 잡는다(`"catapult"` 항목이 예).
2. `python refs_make.py <이름>` → `refs/<이름>/NN.jpg` (00 = 완성품, 99 = 완성), `refs/<이름>/index.json`. 격자 그림이 생긴 뒤에는 다시 돌리지 않는다(NN_2.jpg 가 지워진다, 한 번호만은 `--only N`).
3. 완성품 사진(0)·완성(99)을 등록한다(`refs_upload.js`): ① `refs/<이름>/` 을 `public/_refs_tmp/<이름>/` 으로 복사(커밋 금지, 올린 뒤 지운다) ② 로그인된 조립 보기 화면(`/design.html?subject=robot`)에서 `refs_upload.js` 내용을 실행 ③ `await window.__ivsRefsUpload('<이름>', 'cubo-<권>-<이름>', [0, 99])` (단계 배열을 생략하면 전부). 표 `ivs_assembly_refs` 가 있어야 한다(`supabase/assembly_refs.sql`). ④ 올린 뒤 차시를 다른 차시로 바꿨다가 다시 열고 "🖼 완성 사진" 버튼으로 두 그림이 보이는지 확인한다.

3-2. **완성품 방향선 그림을 만들어 올린다(필수, 00_개선규칙 9번):** ① 완성 사진(00.jpg)에서 배경을 지우고(흰 배경이라 색 기준으로 된다) 6×6 모눈(A~F·1~6)을 얹는다 ② 앞(센서·눈·머리가 향한 쪽)·뒤·위·왼쪽·오른쪽 화살표와 축 표시(앞 +Z · 뒤 −Z · 위 +Y · 왼쪽 +X · 오른쪽 −X)를 그린다. 앞·뒤·위는 3D 완성 화면에서 기준 부품(센서·메인보드·바퀴)의 위치로 확인하고, 사용자에게 보여 주고 확인받는다 ③ `refs/<이름>/00_1.jpg` 로 저장하고 `index.json` 에 `{"step": 0, "idx": 1, "file": "00_1.jpg", "note": "완성품 방향선 — …"}` 를 넣는다 ④ 3번과 같은 방법으로 `__ivsRefsUpload('<이름>', 'cubo-<권>-<이름>', [0])` — 임시 폴더에는 새 그림 1장만 두고 올린 뒤 지운다 ⑤ "🖼 완성 사진"에서 두 그림이 세트로 보이는지 확인한다.

→ 바로 03 부품체크로 이어간다.
