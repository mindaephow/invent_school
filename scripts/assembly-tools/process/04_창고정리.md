# 과정 4. 창고 정리

(03 부품체크가 끝난 뒤. **04 는 1차다 — 책을 훑어 모든 번호에 slot 을 적고 창고가 바뀌는 번호마다 history 를 적으면 끝이며, 상세·정정은 번호 조립 중에 한다: 큐보 부품결합규칙.md A3a.**)

## 번호마다 창고(slot) 정하기
창고 0 = 메인, 1~5 = 따로 만드는 자리. 책을 번호 순서대로 보며 정한다. **1번은 창고 1에서 시작한다.**
1. 창고 정하는 세 가지(연달아 이어지는 번호 = 같은 창고, 새 세트 = 새 창고, "N + M" 합치기 = 앞 창고) → `큐보 부품결합규칙.md` A3.

## 스크립트에 적기
- 번호마다 `kw["slot"] = 번호`. 앞 번호와 slot 이 바뀌면 `history` 글이 반드시 있어야 한다(`build.py` 검사). 창고·불러오기는 번호·설명 본문에 쓰지 않고 `history` 에만 쓴다. 예: "창고 1에서 불러와서 조립 → 그룹 1", "그룹 1 + 그룹 2 합침".
- 그룹 이름·`history` 에만 쓰는 것 → 규칙 A3.
- 다른 창고에서 작업하는 동안 안 보이게 둘 세트: 그 부품들에 `hideAt`(숨길 번호들), `store`({번호: "N번까지 만든 본체"}), `storeThumb`(사진). 사진은 사용자가 📷 썸네일 저장으로 만든다.
- "N~M번 2개 만들기"의 둘째 벌 복사(규칙 A3): M번 부품을 다 놓은 뒤 `s.copy_to_slot(Group("N~M번", [N~M번 부품 전부]), 창고번호, "보관 이름", until=꺼낼 번호)`. 부품마다 창고를 정하는 `slot` 은 화면(`design-assembly.js`)이 보관 카드와 창고 화면에 쓴다.
- 앞 번호에 사용자 ✓ 가 있을 때·`noGuide` → 규칙 A3.
