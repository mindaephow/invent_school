# ───────── 20~22 ── 앞바퀴 팔(115프레임 2장 + 90도 프레임·2단블록 유닛 2개) — 따로 만든다 ─────────
# 팔 좌표(u=길이, 위 y=너비 방향, z=두께): 바퀴 쪽 끝 구멍 k=1(u=−70) … 위쪽 끝 구멍 k=15(u=+70). 세계 위치 = BUILD2 + (u, y, z)
BUILD2 = np.array([150.0, 21.0, -260.0])
def Ap(u, y, z): return BUILD2 + np.array([u, y, z], float)
def hk(k): return -70 + 10 * (k - 1)
R_A = ori("+x", "+z")                                   # 115프레임: 길이 x, 구멍축 z
s20 = step("[교재 20] 115프레임 2개를 나란히 놓고, 한쪽에 리벳 2개(8번째·15번째 구멍)를 꽂아 다른 한쪽을 얹어 붙여요.")
A1 = s20.place("115프레임", R_A, Ap(0, 0, -2.5))
rvA = [s20.attach("리벳", R_A, {"p1": (A1, Ap(hk(k), 0, -2.5))}, rivet=True) for k in (8, 15)]
A2 = s20.recv("115프레임", R_A, [(r, "p2") for r in rvA], p=Ap(0, 0, 2.5), hover=22)

s21 = step("[교재 21] 90도 프레임에 2단블록을 눕혀 돌기 2개를 끼워요(2개 만들어요).")
RL1 = np.eye(3)
RL2 = np.column_stack([(1, 0, 0), (0, -1, 0), (0, 0, -1)])
L1 = s21.place("90도 프레임", RL1, Ap(70, 7.5, 20))
L2 = s21.place("90도 프레임", RL2, Ap(70, 7.5, -20))
RB1 = np.column_stack([(0, 0, 1), (1, 0, 0), (0, 1, 0)])
RB2m = np.column_stack([(0, 0, -1), (-1, 0, 0), (0, 1, 0)])
U1 = s21.attach("2단블록", RB1, {"p2": (A2, Ap(hk(14), 0, 2.5)), "p3": (L1, "h1"), "p4": (L1, "h2")}, hover=22)
U2 = s21.attach("2단블록", RB2m, {"p2": (A1, Ap(hk(14), 0, -2.5)), "p3": (L2, "h1"), "p4": (L2, "h2")}, hover=22)
s22 = step("[교재 22] 유닛 2개의 2단블록 끝돌기를 팔의 14번째 구멍에 양쪽에서 끼워요.")
# 21 의 유닛은 팔에서 떨어진 자리에서 만들고 22 에서 팔에 붙는다(side → 제자리)
def unit_side(pts, dz):
    for pt in pts:
        ex = pt.extra
        ex["side"] = {"p": rnd(pt.p + np.array([0, 40.0, dz])), "r": R_to_euler(pt.R), "until": 22}
        ex["settleDir"] = [0, 0, 1 if dz < 0 else -1]
        if "marks" in ex: ex["settleMarks"] = [list(m) for m in ex["marks"]]
        if "dir" in ex: ex["dir"] = rnd(ex["dir"])
unit_side([L1, U1], 50.0); unit_side([L2, U2], -50.0)

rv24 = [s24.attach("리벳", ori("+x", "+y"), {"p1": (L, Ap(u, 7.5, z))}, rivet=True) for L, z in ((L1, 10), (L2, -10)) for u in (70, 80)]
