# 요청 차이 — 내가 결정한 것과 사용자가 요청·지시한 것의 차이

사용자가 말씀으로 바로잡으신 것을 날짜순으로 적는다(새로 바로잡으시면 맨 아래에 한 항목 추가). 자동으로 모으는 "수정저장 차이"(화면에서 고쳐 저장한 ❄·📷)는 `수정저장차이.md`(`python collect_diffs.py`).
형식: **내 결정** → **사용자 요청** → 배운 것 → 반영한 곳.
