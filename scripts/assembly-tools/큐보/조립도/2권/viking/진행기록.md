## 도구·함정
- **리벳은 항상 결합 전(hover 24 + 화살표), seated 금지** — 21~25번을 seated 로 만들었다가 사용자가 "왜 자꾸 합쳐놓냐"고 지적(2026-10-22)해 분리로 고침.
- 판 격자 없는 번호의 카메라: `bookcam.py <이름> <번호>`(몸통 윤곽 IoU + 리벳 머리 최근접 PnP + 이상점 덜기, `--extra`, `--dry`; `camfit.py` 는 오토건의 다른 도구라 이름 겹침 주의). 같은 번호도 주점을 옮긴 해와 가운데 해가 phi 6° 달랐다 → 겹침 그림(NN_3)에서 상자와 링이 맞는 쪽.
- 격자 파일에 `tool:"infer"` 를 쓰면 `evidence.anchors` 는 개수가 아니라 `[[칸,줄],[x,y],높이]` 목록이어야 rulecheck 가 안 죽는다(`visible_holes` 0, `anchor_mean_px`·`anchor_max_px`·`loo_dtheta`·`loo_dphi` 를 실제로 계산해 적는다). `overlay_check.py` 색 표(COLORS)에 215프레임 등이 빠져 상자가 안 그려져 `setdefault` 로 채웠다.
- 증거가 낡은 번호(앞 번호를 고치면 생김)는 viking.py 를 그 번호까지 잘라 빌드(`--write` 는 마지막 번호만 증거 없이 허용)하고 낡은 evidence 항목을 지운 뒤 다시 record. `madeNoPart` 번호는 verify_step '증거'가 ❌ 로 나오지만 viking_evidence 지문은 일치.
- "아래" 방향은 뷰어에서 불가 → track 에 5방향 기록. `vk_tools.py` = 읽기 표·번호 대조 그림·올릴 파일 복사 반복 도구.
- 새 번호에 `moveMade` 가 있으면 화면은 페이지를 처음 열 때만 앞 번호 부품에 이동 정보를 붙인다 — 전체 새로고침 없이 보려면 `design-assemblies.js` 끝의 병합 코드를 이 조립도에만 다시 실행한 뒤 번호를 1번→N번 순서로 누른다. 새로 열린 페이지는 lift 가 data 에서 자동 적용되지만 이미 열린 화면은 `a.lift` 를 수동으로.
- 어두운 판에서 holefit 가 점을 구멍 사이에 잡으면(7번 DoG 1.50px 통과인데도) 쓰지 않는다. 줄 번호를 책 위→아래 반대로 매겨야 위쪽이 위인 해가 나온다(7·8번).
