# 꼬마기사(cubo-1-kidknight, 큐보 1권, 2족 보행 로봇) 진행기록

대칭 처리는 규칙 파일 F9·F10 을 본다.

## 이 조립도의 구조·고유 사실
- 관절 모터가 돌아 다리가 기울어진다. 다리(검은 39프레임 + 3단블록 2 + 빨간 15프레임)를 T축 구멍(x10, y45) 둘레로 +11.39°(z축) 기울인다. 왼쪽 다리 22~24번, 오른쪽 다리 27~29번(z 거울). 완성 모양은 각각 26~36번 / 30~36번에 이어 간다.
- **21번 연결이 기준이다.** 건드리면 사용자가 크게 화냈다. 뒤 단계를 21번에 맞춘다.
- 기울기 때문에 바닥 아래가 생겨 `A.meta["lift"]` 로 화면을 띄운다(22:10, 23:66, 24:10, 26:10, 27:10, 28:66, 29:10, 30~36:10). 뷰어는 ❄ 기록 부품도 같이 띄운다.
- 화살표 정보 모달(클릭 → 시작/끝/복사 버튼)을 `design.html` 에 추가했다.
- 24·29번 화살표가 6개(가운데 돌기 포함)다 — 교재는 바깥 두 곳. 사용자가 완료 처리했고 빼라는 말은 아직 없다.

## 알아 둘 것
- 아이들이 가장 어려워하는 로봇이라, 새 단계마다 "앞에서 완성한 모양이 이어지는가"를 센다(완성 모양을 뒤 단계에 안 이어 가고 연결을 푸는 실수가 반복됐다).
- 보행 로봇(2·4·6족)을 새로 만들 때는 규칙 파일 F9·F10 과 이 조립도를 먼저 읽는다.
