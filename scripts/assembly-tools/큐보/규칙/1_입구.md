# ① 입구 — 지금 하는 일에 맞는 문서 하나만 연다

조립도 규칙은 **"언제 읽나"** 로 나뉘어 있다. 지금 하는 일에 해당하는 칸의 문서만 읽고, 다른 칸은 그 문서가 가리킬 때만 연다.

| 칸 | 언제 읽나 | 문서 |
|---|---|---|
| ① 입구 | 세션을 시작할 때 | 이 문서 |
| ② 조립도 시작 | 새 조립도를 시작할 때 한 번(01 번호 등록 → 02 그림 → 03 부품 → 04 창고) | `2_조립도시작.md` |
| ③ 번호 하나 | 번호마다 | `3_번호하나.md` — 번호 하나를 처음부터 끝까지 이 순서대로 한다(다른 문서는 여기서 가리키는 부분만) |
| ④ 막힐 때 | 막히거나 책과 다를 때만 | `4_막힐때.md` (증상 → 규칙 → 도구 → 그래도 안 되면) |
| ⑤ 부품 사전 | 그 부품을 놓을 때만 | `5_부품사전.md` (부품 이름별) |
| 규칙집 | ③·④·⑤ 가 규칙 번호(C6·G12·K0 …)를 가리킬 때 그 번호만 | `큐보 부품결합규칙.md` |
| 보관함 | 읽지 않는다 | `보관함.md` (날짜·사건 사례, 옛 규칙) |

- 서버·로그인·최신 받기 같은 세션 준비는 저장소 `CLAUDE.md` "세션을 시작할 때".
- 어떤 내용을 어느 문서에 적는지는 `문서지도.md`.
- 점검기·도구가 "규칙 8"처럼 **"규칙 N"** 이라고 하면 `5_부품사전.md` 공통 B 의 N번(K1 결합 규칙)이다. 규칙집의 B8·G8 이나 ③ 의 "8단계"와 다르다.

## 절대 규칙 5개

1. 사용자의 지시는 좁게 줄여 읽지 않고, 시킨 것만 한다(덤 작업을 붙이지 않는다).
2. 부품 자리는 결합(돌기 ↔ 구멍)으로만 계산한다 — 손 좌표 금지. 결합 판단의 바탕은 물리법칙(K0)이다.
3. 규칙·도구·칩은 "조립도를 책과 맞게 만들기" 위한 수단이다. 책과 맞으면 끝이다.
4. 도구가 통과했다고 규칙을 지킨 것이 아니다. 못 고친 것·어긋난 채 둔 것은 보고에서 먼저 말한다.
5. 규칙은 기억 파일이 아니라 저장소 문서에만 둔다. 바꿀 때는 해당 문장을 덮어쓰고 옛 문장은 지운다(날짜·사건은 커밋 메시지나 `보관함.md` 로).

## 말의 뜻

- **"조립 시작"·"진행해"** = 번호마다 `3_번호하나.md` 1~9단계 전부. 끝 번호가 없으면 완성까지 멈추지 않는다.
- **"사전점검"·"교재점검"** = 책을 읽고 관찰·분석한 것이 맞는지만 본다(③ 2~6·8단계).
- **"조립점검"·"조립검사"** = 규칙(K·G절)을 어기는지 도구로만 본다(③ 7단계의 검사). 책과 비교하지 않는다. 이미 그려진 조립도면 검사 도구를 번호 범위 전체에 돌린다.
- **"조립도 그리기"·"그리고 저장"** = 점검을 마친 조립을 저장하고 책과 맞춰 마무리한다(③ 9단계).
- 말이 애매하면 번호 작업 중이 아닐 때만 한 줄로 어느 쪽인지 묻는다.
