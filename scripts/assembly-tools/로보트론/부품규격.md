# 로보트론 부품 규격 (에이스랩 1~4단계·로보타미주니어 1~5단계)

에이스랩·로보타미주니어는 로보트론 회사 제품이고 큐보와 규격이 다르다. 큐보 규칙·조립도는 `scripts/assembly-tools/큐보/`, 3D 부품 만들기·등록 순서는 `큐보/규칙/06_3D부품_만들기_등록.md` 를 따르고, 이 문서는 로보트론 제품만의 규격을 적는다. 교재·조립도는 아직 등록 전이다(차시 제목만 `ivs_textbooks` 에 있다).

## 1. 규격
큐보 규격과 다른 점(사용자 2026-10-25~27) — 큐보 프레임에서 아래만 바꿔 유추한다. 사용자가 요청하기 전에는 부품을 만들거나 기존 부품을 고치지 않는다.
- 구멍 입구 홈 없음·구멍 지름 4.5(반지름 2.25, 큐보 목 5.5보다 1mm 작음). 두께 5·전체 크기는 큐보와 같다.
- 구멍 한 칸(10×10)마다 가장자리 테두리와 같은 네모 테두리로 둘러 구멍 사이에 선이 생긴다(15프레임이면 4줄). 구멍 둘레 동그란 고리는 없다.
- 팔 끝 모서리 반지름 4.5(안쪽 3.5, 짧은 변은 자동으로 줄임). 칸 단위 타일로 면을 나눈다(전체를 한 번에 나누면 격자 안쪽 칸을 못 잇는다).
- 색: 프레임 #F45243(이름 "다홍색", 부품 만들기 "자주 쓰는 색"에 있음), 리벳·부시·축 블랙. 리벳 몸통 2.1·머리 2.6·가운데 마디 2.2.
- 생성기: `app/lib/robotron-frame-mesh.js`(공통 틀)·`junior-frame-mesh.js`·`acelab-frame-mesh.js`·`junior-rivet-mesh.js`. 등록: `scripts/make-junior-parts.mjs [--write]`(큐보 프레임 18종+리벳을 새로 만들고 부시·축은 블랙 복사, 같은 이름은 행을 덮어씀). 에이스랩 부품은 아직 DB 에 없다.
- 출력용은 `make-robotron-print.mjs`(`큐보/규칙/06_3D부품_만들기_등록.md` 5-4). 목 지름은 큐보 +0.60 을 그대로 적용한 가정(4.5 → 5.10)이며 눕혀서 출력한다.
- 부품 행을 DB 에 직접 쓰면 `thumbnail3d` 가 비므로 06 문서 4절대로 "✅ 골라서 그리기"까지 한다(안 하면 설계 화면에 옛 SVG 가 뜬다).

## 2. 3D 모델 테두리 선 (사용자 2026-10-27)
- 모든 부품에 실제 윤곽을 따라 아주 얇은 선(0.1mm)을 긋는다 — 사각 상자 둘레가 아니라 바깥 둘레(둥근 모서리 포함)·구멍 둘레·붙은 부품의 경계. 두껍게(0.5)·흰색에 가까운 색은 안 된다.
- 색은 부품 색이 어두우면 조금 밝게, 밝으면 조금 어둡게(`app/lib/robotron-line-color.js` 의 `lineColorFor`). 본보기: `scripts/make-robotron-flatplate.mjs`(고리→막대 방식).
