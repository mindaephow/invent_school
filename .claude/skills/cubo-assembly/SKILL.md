# 큐보 조립도 작업 — 입구

**이 파일은 입구일 뿐 규칙을 담지 않는다.** 규칙은 `scripts/assembly-tools/큐보/규칙/` 의 문서에 "언제 읽나" 기준으로 나뉘어 있다. 지금 하는 일의 문서 하나만 읽는다.

1. **`큐보/규칙/1_입구.md`** — 어떤 문서를 언제 읽는지(5칸)와 절대 규칙 5개.
2. 새 조립도면 **`2_조립도시작.md`**(01 번호 등록 → 02 그림 → 03 부품 → 04 창고)를 한 번 따라간다.
3. 번호마다 **`3_번호하나.md`**(늘 지킬 것 6개 + 1~9단계)만 보고 끝낸다. 첫 보고에 "이번 번호에서 지킬 규칙 3개"를 적고 `python number_start.py <이름> <번호>` 부터 돌린다(서버·로그인·`.env.local` 은 저장소 `CLAUDE.md` 시작 절).
4. 막히면 **`4_막힐때.md`**, 부품을 놓을 때는 **`5_부품사전.md`** 의 그 부품 항목만 연다. 규칙 번호(B7·C6 …)는 규칙집 `큐보 부품결합규칙.md` 에서 그 번호만 찾는다.

명령 사용법·코드 템플릿은 `큐보/규칙/05_조립.md`, 조립도별 진행 상태는 `큐보/조립도/<권>권/<이름>/진행기록.md`, 사용자가 바로잡은 사례는 `user_diffs/요청차이.md`, 화면 조작 코드는 `큐보/규칙/viewer_snippets.md`.
